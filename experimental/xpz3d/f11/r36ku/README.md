## 실제 변경

원본에서 노멀맵이 없었던 얼굴, 목, 팔, 손목, 손가락 등의 피부 부위에 rest-space 기반 미세 표면 노멀과 거칠기 맵을 추가했다. 동일한 3D 위치에서 동일한 결정적 미세표면 함수를 샘플링하고, 각 삼각형의 실제 탄젠트 기저로 변환했다. UV 차트 경계에는 1024에서 3픽셀, 512에서 2픽셀 여백을 넣었으며 저해상도 차트는 고주파를 약화했다.

헤어는 기존 헤어 컬러 텍스처의 결을 기초로 얕은 표면 노멀과 거칠기 맵을 만들었다. 새 헤어컷을 만들거나 기존 헤어 컬러를 다시 그리지 않았다.

변경 primitive: `0, 1, 2, 4`. 새 노멀맵 적용 범위는 1,414삼각형이다. 기존 몸통·어깨·다리 primitive `7~11`과 그 재질은 이번 버전에서 변경하지 않았다.

보존 항목: 모든 원본 삼각형 코너의 POSITION, NORMAL, JOINTS_0, WEIGHTS_0, COLOR_0와 기존 UV 값, 본 목록과 계층, inverse-bind 행렬 값, 원래의 다섯 내장 이미지 바이트, baseColorFactor/baseColorTexture. 접근자 번호와 정점 인덱스는 재패킹 때문에 바뀔 수 있다. 원본 스키닝의 9개 자세 결과를 이번 엔진 테스트로 잘못 표기하지 않는다.

새 외부 텍스처: 피부 NORMAL/MR 각 1024와 512, 헤어 NORMAL/MR 각 256. MR의 G는 roughness, B는 metallic이며 R=255는 미사용이다. 기존 피부색에 AO를 덧칠하지 않았다.

## 중요한 정정: 6,000 → 2,100이라는 해석

R36KS 메타데이터의 `donorOriginalTrianglesNotEmbedded: 6044`는 별도 고밀도 공여 메시의 삼각형 수다. 이것만으로 전체 캐릭터가 6,000에서 2,100으로 줄었다고 결론낼 수 없다. 이전 R36KT 설명의 '전체 약 3,900삼각형·65% 감소'는 입증되지 않은 해석이므로 폐기한다.

**이번 출력은 공여 메시에서 베이크한 원형 복원본이 아니다.** 현재 확인한 R36KS를 기준으로 비어 있던 표면 표현을 추가한 새 저폴리 보강본이다. 실루엣과 관절의 잃어버린 체적까지 복원했다고 주장하지 않는다. 새 피부 노멀의 최대 기울기는 1024 약 2.65도, 512 약 2.06도이며 헤어는 약 8.24도다. 변화가 미세한 것은 얼굴과 피부색을 유지하기 위한 의도된 제한이다.

## 열어 보기

`preview/index.html`을 다운로드하여 직접 연다. three.js 렌더러, R36KS 1024, R36KU 1024/512가 모두 HTML에 내장되어 있다. 인터넷, CDN, 로컬 HTTP 서버 없이 `file://`에서 동작한다.

얼굴·헤어, 팔·손, 전신 시점, 1024/512 선택, 새 디테일 토글, 조명 없는 색상 모드, 와이어 표시, 비교용 합성 팔·다리 포즈를 제공한다. 왼쪽을 드래그하면 양쪽 카메라가 같이 움직인다. 조명과 색 관리는 두 모델에 동일하게 적용되지만 **S2/S3 엔진 색감의 정답이라고 보장하지 않는다.**

`preview/R36KU_COMPARE_HEAD.png`, `R36KU_COMPARE_ARM.png`, `R36KU_COMPARE_FULL.png`, `R36KU_ALBEDO_PRESERVED.png`, `R36KU_COMPARE_512.png`는 실제 GLB를 headless Edge/three.js로 렌더링한 캡처다.

## 재생산

```powershell
python -m pip install -r requirements.txt
python prepare_r36ku.py
python build_r36ku.py
npm install --prefix viewer_deps --no-audit --no-fund three@0.170.0 esbuild@0.24.0 gltf-validator@2.0.0-dev.3.10
python build_preview.py
node validate_glb.cjs
# 아래는 Microsoft Edge와 Playwright가 있는 환경에서만 필요하다.
python review_r36ku.py
```

`prepare_r36ku.py`는 원본을 고정 커밋에서 받는다. 이미 포함된 `source/output/*.glb`와 헬퍼를 쓰면 준비 단계를 생략할 수 있다. 빌드는 원본 SHA-256 불일치 시 중단한다. 자동 업로드는 `publish_r36ku.py`이며 gh 로그인과 명시적인 `--publish` 인자가 필요하다.

## 확인 결과와 미완료

실제 GLB 2개 생성 및 삼각형별 원본 속성 보존 검사 통과. 파일 내부 이미지·색·리깅 유지 통과. glTF Validator 오류는 양쪽 0개, 경고는 각 30개이며 상세 목록을 첨부한다. 모든 경고가 해결된 것으로 표기하지 않는다. 기존 몸통·다리의 런타임 탄젠트 생성, 스킨드 노드 계층, 0가중치 슬롯의 관절 인덱스 관련 경고가 포함된다.

비교 뷰어는 headless Edge에서 file://로 세 모델을 로드했고 JavaScript 오류가 없었다. 게임 설치폴더는 수정하지 않았으며 S2/S3 실행·애니메이션·프레임레이트 검증은 하지 않았다.
