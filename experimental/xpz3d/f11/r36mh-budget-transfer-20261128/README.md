# R36MH — 물리적 삼각형 예산 회수·재분배 생산기

## R36MG 이후 실제 개발 내용

기존 R36MG는 8개 공유 모서리를 뒤집었지만, **신체의 다른 영역에서 삼각형을 회수해 목표 윤곽에 새 삼각형을 공급한 것은 아니었다.** R36MH는 몸체 내부에서 안전한 에지를 축약하는 작업과, 구조 랜드마크 주변의 삼각형을 중심 정점으로 세 개로 나누는 작업을 연결했다.

- 기하 생산기: `source/build_r36mh.cjs` (Node.js 22)
- GitHub Actions: `.github/workflows/xpz3d-r36mh-budget-transfer.yml`
- 비교 뷰어: `preview/index.html`
- 출력: `output/compact/R36MH_<ART|SUBTLE>_<DENSE|GUARDED>_2100_COMPACT_FULL.glb` 와 `_CLAY_` 모델
- 실행 보고서: `output/<variant>/R36MH_<STRONG|GUARDED>.report.json`

## 알고리즘과 구조 보존

1. R36MG 전신 GLB의 몸체 1,132삼각형을 물리 3D 정점 위치별로 묶고 공유 에지 인접 그래프를 작성한다.
2. 중심부 목표 범위 바깥의 평탄한 에지 가운데, 경계 정점이 아니며 링크 조건·면적비·면 법선 방향·스킨 웨이트 차이를 만족하는 내부 에지를 축약한다. **축약 1회당 삼각형 2개를 회수한다.**
3. 중앙 구조의 8개 윤곽 곡선에 가깝고 상대적으로 넓은 삼각형을 찾는다. 중심 정점의 위치와 본 인덱스·가중치·법선·탄젠트·UV·색상을 보간한다.
4. 해당 삼각형 하나를 3개로 나누면서 작은 깊이 조형을 추가한다. **분할 1회당 삼각형 2개가 순증가한다.**
5. 회수한 삼각형과 새로 추가한 삼각형 수가 같아야 GLB를 내보낸다. 전체 몸체 1,132, 얼굴·헤어 968, 전체 2,100, 63본을 유지한다.
6. 변경된 표면의 기하 법선 및 접선 방향을 정리하고, 기존 UV 안의 노멀 세부 정보를 옛 TBN에서 새 TBN으로 이송한 2048 노멀맵을 만든다.
7. 동일한 전체 모델을 단색 무광 CLAY 버전으로 만들어 기존 R36MG와 형상 중심으로 비교한다.

## 실제 구현 범위

- **삼각형의 부위 간 순수한 숫자 예산 재배분을 최초 구현한 생산기 후보**다. 물리 에지 축약과 삼각형 중심 분할을 함께 사용한다.
- 완전한 수동 리토폴로지, 목표 사진의 원근 보정, 정확한 깊이 복원은 포함되지 않았다.
- 기존 색상 텍스처는 유지하고 수정된 부분의 노멀맵을 추가 갱신한다. 원본 사진을 그대로 GLB에 삽입하지 않는다.
- 내부 정점 축약으로 인한 스킨 표현 품질과 애니메이션의 실제 S2 게임 엔진 동작은 별도 미확인 상태다.
- 사진에서 추정한 2D 윤곽은 조형 가설이다. CLAY가 목표와 다르면 텍스처를 과도하게 그리는 대신 형상을 재설계해야 한다.

## 상태 및 인계

Node.js 생산기와 워크플로 및 비교 뷰어 소스의 GitHub 게시 완료. 작업이 성공한 후에는 `R36MH_*.report.json`에서 실제 회수 수, 추가 수, 수정 정점/UV, SHA를 확인한다. GLB 빌드 성공과 실제 GitHub 게시, 미술적 승인 및 S2 엔진 성능은 각각 구분한다.

다음 단계에서는 실제 렌더 캡처를 사용해 R36MG/R36MH의 0°·35° 단색 모델을 비교하고, 중심부 구조가 여전히 부족하면 더 많은 **고유 정점**이 구조 영역에 투입되도록 후속 리메시를 개선한다. 정량 지표만으로 미술 품질을 승인하지 않는다.
