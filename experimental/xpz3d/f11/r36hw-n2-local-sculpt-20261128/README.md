# R36HW N2 — HW 원본 기반 국소 메시 조형

## 실제 제작 범위

원본 `r36kp/reference/R36HW_F11_CLOTHED.glb`의 스킨, 얼굴, 머리카락, 몸체 토폴로지 기반으로 작업한다. R36JB를 일절 읽지 않는다. 기존 외부 장신구 186개 삼각형을 제거하고, 기존 바지/골반 전방 표면의 삼각형을 중심 분할하여 국소 곡면의 정점을 추가한다. 영역 바깥은 원본 인덱스/버퍼를 유지하며 새 정점의 JOINTS_0 / WEIGHTS_0는 인접 정점에서 보간·정규화한다.

명암 레퍼런스: 사용자가 첨부한 단일 이미지에서 추출한 **9열 × 15행 밝기 표본(135개)**과 수동 구조선 함수를 조합한다. 사진 전체를 텍스처나 GLB에 삽입하지 않는다. 국소 메시 정점에 제한적인 상대 깊이만 적용한다. 추출한 밝기는 실제 깊이를 보장하지 않는다.

예상 산출물: `output/R36HW_N2_REGION_SCULPT.glb`과 `reports/R36HW_N2_REGION_SCULPT.json`.

## 재현 실행

```bash
node experimental/xpz3d/f11/r36hw-n2-local-sculpt-20261128/source/build_r36hw_n2.cjs
```

원본 SHA-256을 `a0780ab8995e68036388754449cfb66891c8bbbb160ef18b04a730d3294db732`와 비교한다. glTF primitive의 실제 원본 수량 **2,098삼각형**, 63본을 필수 조건으로 검사한다. N1의 2,100 삼각형 고정 검사로 인한 CI 실패를 수정했다.

## 명확한 한계

이 결과는 **국소 메시 깊이 시제품**이다. 아직 옷 전체의 토폴로지를 인체 표면으로 교정하지 않았으며 사진과의 외관 일치도 승인도 완료되지 않았다. 2,100삼각형 이하이고 GLB가 유효하더라도 최종 탈의 모델로 표시하지 않는다. 사용자의 기존 S2 네이티브 실행 환경에서의 렌더링 및 동적 스키닝은 별도 단계이다.

렌더링 품질 평가의 목표는 실루엣 보존과 실제 곡률 연속성이다. 사진의 실제 3차원 깊이는 불명확하므로 단일 이미지의 명암을 절대 높이로 해석하지 않는다.
