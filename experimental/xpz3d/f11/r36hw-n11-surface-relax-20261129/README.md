# R36HW-N11 — 원본 몸체 계승형 곡면 완화

이 버전은 N10의 실제 개방형 골반 메시를 계승하면서 **경계 정점 45개를 보호**하고 의복 유래의 중앙·측면 삼각형 패싯을 재조형한다. R36JB 몸체 전체 교체, 목표 사진 투영, 원본 얼굴·머리카락 변경은 수행하지 않았다.

## 실제 결과

- **1,985삼각형**, 골반 249삼각형, 골반 정점 183개
- 기존 정점 72개 수정, 그중 측면 조정 33개
- 중심부 16정점에 약한 실제 깊이 변화를 적용
- 허리·다리의 원본 피부 연결 경계 45정점은 그대로 고정
- 누적 정점 변위를 **15mm 이하**로 제한
- 기존 63본 유지, 원래 644삼각형 얼굴 및 294삼각형 머리카락 메시 유지
- 12종 정면/사선/측면 · 전신/중심부 · CLAY/색상 진단 캡처

```bash
node experimental/xpz3d/f11/r36hw-n11-surface-relax-20261129/source/build_r36hw_n11.cjs
```

출력: `output/R36HW_N11_SKIN_RELAX.glb`, `reports/R36HW_N11_SKIN_RELAX.json`.

시각적 비교: `../r36hw-n11-mesh-render-20261129/output/`.

## 미완료 / 자체 피드백

실제 CLAY 정면 캡처에서 원래 반바지형 실루엣이 여전히 남는다. 이는 중심부의 높이 변화가 부족한 문제만이 아니라, **피부가 아닌 의복형 토폴로지가 그대로 남아 있기 때문**이다. 따라서 본 작업물을 최종 탈의형이라고 승인하지 않는다. 기존 정점 이동만 계속해도 이 근본 문제가 해결되지 않는다.

남은 작업은 국소 재토폴로지와 원본 허벅지 및 복부 테두리의 실제 인덱스 접합, 빈 내부 피부의 복원, UV 재배치, 네이티브 S2의 PBR·실시간 63본 스키닝이다. CPU 이미지 캡처는 네이티브 S2 결과가 아니다.
