# R36HW N8 — 원본 HW 기반 하단 밀착과 곡률 완화

## 실제 조형 변화

N6 원본 기반 골반 영역을 직접 수정한다. 63본·원본 얼굴/머리카락 구조는 그대로이며 R36JB 몸체를 가져오지 않는다.

- 원본 노출 다리의 좌우 각 7정점 링을 사용해 골반 하단을 위치별로 연속적으로 밀착시킨다. N7B의 최대 11.5mm 보정 상한을 **22mm**로 조정하되 전면 조형을 과도하게 이동시키지 않도록 범위를 제한한다.
- 전방 골반의 기존 174정점에 곡률 보존형 약한 라플라스 완화를 추가한다.
- 이미지 자체를 UV 텍스처로 붙이지 않고, 구조선 기반의 약한 접힘·함몰을 실제 정점 변화로 반영한다.
- 중심부 곡률이 높은 삼각형 9개를 각각 3개로 세분화하여 총 **18삼각형을 추가**한다.
- 전체 2,098삼각형, 63본 유지. 원본 HW의 얼굴 644삼각형과 머리카락 294삼각형 불변.
- 별도 GitHub Actions 및 Node.js 22 생산기.

### 실행

```bash
node experimental/xpz3d/f11/r36hw-n8-soft-legfit-20261128/source/build_r36hw_n8.cjs
```

**원본 파생 경로:** HW → N3 → N4 → N5 → N6 → N8. 이 버전은 다른 패치에서 몸체를 가져오지 않는다. N7B의 조형 루틴을 수정하되 원래 N6 GLB로부터 재생산한다.

### 완료 상태

- 생성 GLB와 재현 생산기: GitHub 게시
- 실제 골격 구조 63본: GLB 상 유지
- 바지형 원본 표면 토폴로지: 여전히 남음. **완전 탈의·실제 피부 교체가 완료된 것이 아님**
- 네이티브 S2 UV/스키닝: 별도 과제
- 최종 미술 품질: CLAY/음영 실제 렌더를 비교하여 결정. 2,098삼각형만으로 승인 불가.

*정면 확대에서 접힘이 삼각형 조각처럼 보이면 N8도 불합격이며, 진짜 국소 재토폴로지가 필요하다.*
