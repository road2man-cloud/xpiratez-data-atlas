# R36KV — 골반저 삼각형 재배분 + HW 방향의 연속 아트 피부 텍스처

**상태:** 실제 GLB 2종, 2048² 텍스처 4종, 대시보드, 포즈별 브라우저 캡처 생성. **HW 수준 최종 완성본은 아님.**

## 제작 목표와 달성한 범위

사용자가 표시한 상부/바깥 허벅지 평면은 고밀도 분할이 필요하지 않다고 지적했다. R36KV는 R36JB의 고밀도 몸체 12,896삼각형을 먼저 880삼각형으로 줄인 다음, 연결된 폐쇄 몸체 표면에서 골반저 중심으로 **120회 에지 분할(240삼각형 증가)**을 전부 배치한다. 따라서 968삼각형의 R36HW 원본 얼굴·헤어와 합쳐 **총 2,088 / 제한 2,100**삼각형이다. 허벅지에 붕 뜬 중심해부학 조각은 추가하지 않는다.

| 구분 | 삼각형 |
|---|---:|
| R36HW 얼굴·헤어·눈·장식 | 968 |
| 전신 및 골반저의 단일 폐쇄 몸체 | 1,120 |
| 별도 중심부 섬 | 0 |
| **총합** | **2,088** |

세분화 분포(소스 Z 좌표): 골반저 Z<0.945에서 120회, 그 위의 transition/upper에서 0회. **이는 추가 세분화만의 분포이며, 기존 880삼각형까지 모두 골반저에 배치했다는 뜻이 아니다.** 소스 본래의 형태가 가진 허벅지 사이의 빈 공간은 남는다.

## R36HW 피부색 기반의 아트 텍스처

단지 PNG 크기만 올린 방식이 아니라 월드/바인드 공간에서 독립적인 텍스처 레이어를 생산한다. 1,120개 피부 삼각형의 UV는 별도 아틀라스 섬이지만, 채색의 정의는 **연속된 3D 좌표**를 이용해 삼각형 경계의 톤 차이를 줄인다.

- R36HW 얼굴의 따뜻한 피부 재질을 색상 설계의 출발점으로 하되, R36JB 몸체 원본 색상 정보로 변조한다. R36HW 원본과 완전히 동일한 색이라고 주장하지 않는다.
- 골반 주름, 복부·고관절 음영, 허벅지 볼륨 강조를 곡면 위치에 따라 별도 손그림식 영역 레이어로 생성한다.
- 3D 조합형 저주파/고주파 피부색 노이즈, 미세 점, 모공 노멀, 부위별 거칠기를 만든다.
- 고밀도 원본 몸체 12,896삼각형의 표면 법선과 골반저 상세 원본 6,044삼각형의 일부 법선 방향을 참고해 2048² 노멀맵을 굽는다.
- 2048² Base Color, Normal, ORM, Height/Relief를 PNG로 개별 배포하고 색상·노멀·ORM을 GLB에 내장한다.
- **UV 섬 외부 검은 패딩 복사 오류를 수정했다.** 패딩 색이 잘못 섞이지 않도록 내부 픽셀의 안전 여백을 두고 복제한다.

`output/PRODUCTION_REPORT.json`에서 실제 베이크 된 내부 삼각형 픽셀 수, 고밀도 참조 수, 채색 분포, 해시를 확인할 수 있다.

## 생성된 모델

- `output/R36KV_2088_ART_FLOOR.glb`: 골반저 중심으로 메시를 배분한 기본 아트 모델.
- `output/R36KV_2088_ART_STABLE.glb`: 전면 골반부의 Hip 스킨 가중치를 추가로 보정한 **대시보드 기본 모델**. 기존 `../r36kp-pelvis-skinlab-20261128/source/pelvis_skin_anchor.cjs`를 재사용한다.
- `preview/index.html`: 두 R36KV와 기존 R36KP, 고밀도 참조를 같은 카메라에서 비교. 0°·18°·35° 벌림 및 색상/노멀 표시 선택.
- `preview/captures/`: 0°/35° 실제 브라우저 출력.
- `source/build_floor.cjs`, `reallocate_floor.cjs`, `skin_art.cjs`, `bake_atlas.cjs`: 핵심 생산기.
- `source/glb_io.cjs`, `mesh_qem.cjs`, `surface_patch.cjs`: 고밀도 소스와 메시 처리 도구.

## 재생산

원본 R36HW/R36JB GLB가 같은 PC에 준비돼 있어야 한다.

```bash
node source/build_floor.cjs path/to/R36HW_F11_CLOTHED.glb path/to/F11_R36JB_GPT62_NUDIST_CLEAN_ANATOMY_MASTER.glb output/new_build --atlas=2048
node ../r36kp-pelvis-skinlab-20261128/source/pelvis_skin_anchor.cjs output/new_build/R36KV_2088_ART_FLOOR.glb output/new_skin
```

작업은 JavaScript/Node.js로 진행되었다. **Windows 로컬에서 Python을 실행하지 않았다.** GPT 내부 환경은 GitHub 원본 GLB를 DNS 제한 때문에 직접 읽을 수 없어, 원본이 저장된 사용자 허가 Windows 환경에서 최종 Node 빌드를 수행하였다.

## 품질 한계 및 다음 작업

기존 R36KP의 검은 음영, 극단적으로 각진 골반부 실루엣과 UV 섬 단위의 노멀·탄젠트 차이가 **아직 완전히 해결되지 않았다**. 이번 재배분과 월드 좌표 기반 아트 레이어는 실제 작업물이며, HW의 장비 텍스처처럼 완성된 수작업 아트라고 포장해서는 안 된다. 0°/35° 렌더를 보고 감점되는 부분은 극도로 얇은 슬리버 삼각형, 평면 피부 음영, 기존 몸체의 골반저 토폴로지다.

후속 작업은 (1) 연결된 하부 메시의 날카로운 슬리버/곡률을 정돈하고 (2) 정상적인 UV 섬 경계의 탄젠트 정합과 (3) R36HW 스프라이트 대비 색상 조정, 그리고 (4) 게임 엔진 재질/스키닝 테스트로 이어가야 한다. **현재 게임 엔진에 적용되었다는 증거는 없다.**

기존 안정 GLB와 타 개발자의 소스는 변경하지 않는다.
