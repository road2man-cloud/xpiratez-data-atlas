# R36HW F11 V15 interchange package

Lossless external-resource glTF export of V14. Includes 6 mesh primitives, 2,100 triangles, 63 joints, 112,576-byte model binary and four original PNG textures. The interchange manifest documents joint hierarchy, material assignments and root coordinate transform. This is standard glTF, not a native S2 compiled model. No S2 import or render was performed.

Rebuild: `node experimental/xpz3d/f11/r36hw-athletic-v15-interchange-20261129/source/build.cjs`.
