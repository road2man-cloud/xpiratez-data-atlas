# R36HW N16 — 원본 중심부 3D 연결 개선

## 실제 완성된 산출물

- `source/build_n16.cjs` — **실제 채택한** 원본 3D 내부 에지 재배치 Node.js 생산기
- `output/R36HW_N16_RETESS_CENTER.glb` — 실제 기존 GLB를 수정한 게임 모델
- `reports/R36HW_N16_RETESS_CENTER.json` — 에지 이동 수, 품질 변화, SHA-256 등
- `../r36hw-n16-center-render-20261129/output/` — 실제 중심부 CLAY/색상 6장

기본 입력은 `../r36hw-n15-center-continuity-20261129/output/R36HW_N15_CENTER_CONTINUITY.glb`이다. 기존 R36HW 계보에서 얼굴·머리카락과 다른 메시 원본은 유지한다.

## 실제 결과

- 2,099삼각형, 63본, 전체 폴리곤 추가 없음.
- 중심부 삼각 내부 에지 **13곳**을 면 방향을 유지하면서 교체.
- 법선 정점 **34개** 재계산.
- 정해진 형상 지표에서 품질 0.3 미만 삼각형: **20개 → 19개**.
- 원본 위치·UV·JOINTS_0·WEIGHTS_0를 그대로 보존하고, 중앙 primitive의 삼각 인덱스와 국소 법선만 교체.

## 실패한 실험과 처리

`source/retess_patch.cjs`는 기존 중심부 40정점 경계를 단순 2D 다각형으로 취급해 삼각형을 전면 재배치하려던 실험이며, **현재 채택한 생산기가 아니다.** 원래 3D 곡면을 XZ 평면으로 투영할 때 경계가 겹쳐 귀 자르기 방법이 실패했다. 실패 결과를 GLB로 게시하지 않았다.

현재 채택 생산기는 원본 3D 메시에서 법선·경계 방향을 유지하는 내부 에지 플립 방식이다.

## 미술 품질 상태

N16 실캡처에서도 중앙의 삼각형 음영과 의복에서 유래한 하부 윤곽이 뚜렷하다. 사용자 목표 이미지와 유사한 중심부는 아직 완성되지 않았다. 네이티브 S2 렌더와 실시간 63본 스키닝은 미확인이다. 전체 신체 조형이 아니라 골반 중심부 국소 면과 경계 접합에만 후속 작업을 집중한다.

```bash
node experimental/xpz3d/f11/r36hw-n16-retess-center-20261129/source/build_n16.cjs
```
