# V26 sleeve skinning GLB

V25-based opaque athletic outfit. Constrained joint-weight redistribution on sleeves only, evaluated in three arm-lowering poses, retaining at most four influences and original mesh, UVs, material, skeleton, inverse binds and default pose. The optimization metric is a local edge-length distortion proxy, not a visual quality score. No native S2, render or collision test was performed. No torso or pelvic edits.

Rebuild: `node source/build.cjs /path/to/V25.glb`.
