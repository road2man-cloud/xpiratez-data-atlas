# XPZ3D F11 R36KK — 실제 3D 위치 기반 텍스처 이음매 개선

## 결과
- 기존 R36KJ 실제 GLB를 가공한 R36KK 품질형/경량형 **2종을 직접 생산**
- **2,100삼각형, 63본 유지**; 모든 정점 POSITION과 인덱스, 스킨 웨이트 유지
- R36HW 얼굴(644△), 헤어(294△), 눈, 손 원본 프리미티브 변경 없음
- 몸통/좌우 어깨/좌우 다리 UV를 실제 3D XYZ 위치로 역투영하여 **부위 사이 동일 피부색 함수**로 다시 베이킹
- 신규 Albedo, Normal, ORM 3종 (각 1024px / 512px); 메시 법선 미세 부드럽게 조정
- 비활성 R36KI·R36KJ 텍스처 및 미사용 GLB 접근자/재질/이미지 제거, 실제 모델 사이즈 경량화
- 원본 R36HW SHA-256: a0780ab8995e68036388754449cfb66891c8bbbb160ef18b04a730d3294db732
- 1024 품질형: 400,972 bytes / SHA-256 a33df6ea166f5c08ab70d735f4c8caa150fc5810ed2bb7990247bd63a6ed3ff7
- 512 경량형: 291,676 bytes / SHA-256 02dabe0439972dd2a4799bc8f58811c54aae636b1464e33f72b040f879a16cc8

## 실측 / 인과 구분
- 몸통↔어깨·다리 근접 정점 **64쌍** (정지 자세 XYZ 0.04미터 이내)에서 텍스처 RGB 거리 평균:
  - 1024: 37.2558 → 3.7219
  - 512: 20.307 → 3.6313
- 위 수치는 표면 색의 연결성에 관한 것이며 **기하학 틈새나 실제 동작 품질 지표가 아닙니다.**
- 메시에 새로운 면을 추가하지 않았고 어깨/허벅지의 실제 틈은 남아 있습니다.

## 재생산
Python 3, NumPy, SciPy, OpenCV-Python, Pillow 설치 후 동일 폴더에서 `python build_r36kk.py` 실행. 원본 2종 R36KJ GLB, R36HW GLB, 스프라이트, glb_io_r36kj.py, compact_gltf.py를 보존해야 합니다.
`python package_r36kk.py`를 실행하면 오프라인 대시보드/ZIP을 다시 제작합니다.

## 미완료
R36JB의 고밀도 중심해부학을 2,100△의 실제 저폴리 형상으로 완전히 통합한 것이 아닙니다. 원본 신체 외형은 비노골적이고 부분적인 외관 모델이며, S2/S3 게임 엔진 피격/방어구/동작 호환성을 확인하지 않았습니다. 소프트웨어 렌더는 GLB 입력을 사용하나 PBR 엔진 완전 재현이 아닙니다.
