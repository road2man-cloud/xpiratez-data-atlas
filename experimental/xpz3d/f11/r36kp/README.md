# XPZ3D F11 R36KP — 필수 인계 / Development Handoff

업로드 날짜: 2026-11-27. 본 브랜치는 `main`의 X-Piratez 게임 데이터와 별도로 관리하는 3D 실험 작업용입니다.

## 기준과 우선순위

- **외형 기준**: `R36HW_F11_CLOTHED.glb` (SHA-256 `a0780ab8995e68036388754449cfb66891c8bbbb160ef18b04a730d3294db732`)
- **전투용 최근 모델**: R36KP 1024/512, 2,100 triangles, 63 bones
- **비의복 파트**: R36HW 얼굴(644△)·헤어(294△)·눈·머리핀·손·기존 피부와 원본 재질 보존
- **중심해부학**: 고밀도 R36JB 6,044△은 편집용 참조. 전투용 메시에는 전체 도너가 들어간 것이 아니라 40△ 저폴리 패치가 포함됨
- **색상 디자인 기준**: 원본 F11 스프라이트와 스프라이트 기반으로 보정된 **어두운 R36HW 피부톤**. 밝은 PBR 화면을 디자인 정답으로 취급 금지
- **렌더 비교**: R36HW 원본 CPU/Canvas 뷰와 Three.js PBR 뷰의 조명 방식은 서로 다름. S2 엔진 캡처 없이는 어느 쪽도 엔진 출력과 일치한다고 확정 금지

## R36KP 실생산

- R36KO 1024/512 GLB에서 피부 메시 변경.
- 중심 패치 40△ 유지, 정점 24개를 더 후방(posterior, 최대 0.005423395 모델 단위) 및 상방(superior, 최대 0.001910448 모델 단위)으로 조정; 원래 앵커 인덱스 2·3 보존.
- 양측 허벅지 안쪽 상단 각각 5정점 이동. 접합 간격 평균: 좌 0.0158299→0.0121201, 우 0.0161061→0.0122931 모델 단위. **완전 용접은 아님**.
- 피부 Albedo, Normal, ORM 텍스처 갱신, 미사용 GLB 리소스 제거.
- R36KP 1024 GLB: 424,876바이트; SHA-256 `285d9c17848992231da5ffc10ebc6d807b52da1e577c64147bb5408a53584829`
- R36KP 512 GLB: 309,392바이트; SHA-256 `1a89353c3a2b15cf1e0073be2c72c2b962bd263622b3288e1f678c39e6112c04`

## 다음 작업자 실행 순서

1. GitHub 저장소에서 실제 바이너리/소스 업로드 상태를 먼저 확인. 존재하지 않는 파일은 누락으로 기록하고 사용자에게 재확인을 요구하기 전에 접근 가능한 원본을 탐색.
2. 실제 R36KP GLB가 존재하면 SHA 검증 후 1024판을 다음 모델의 기준으로 사용. 없다면 **R36KP 완료본을 GitHub에서 받았다고 주장하지 말 것**.
3. 스프라이트와 원본 R36HW를 동일한 조명 조건으로 비교. 피부/얼굴/헤어를 밝게 변경하지 말고 R36HW 의복 부위 외 형상·재질 고정.
4. 중심 패치를 후방·상방에 자연스럽게 연결하되 폴리곤 총합 2,100△ 유지. 큰 실루엣은 기하학, 미세 굴곡은 UV Albedo/Normal/ORM.
5. 골반·허벅지/어깨 접합 구조 및 스킨 가중치를 개선. 원본 얼굴 헤어 손 프리미티브 재조형 금지.
6. GLB 실생산 → 렌더 비교 → 최소 QA → 보고서. 63본, 보호 프리미티브, 좌표계, 노멀, 관절 변형과 색감은 구분해서 검증.
7. S2/S3 엔진 적용은 아직 **미완료**. 통합 테스트 성공 전 게임 적용 완료로 표시 금지.
