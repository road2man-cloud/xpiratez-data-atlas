# R36HW N17 — 골반 중심부 실제 메시 깊이/곡률 개선

R36HW 원본 계보의 N16 GLB를 입력으로 사용한다. 별도 사진 이미지 생성·붙여넣기·UV 투영·전신 재조형·R36JB 몸체 교체를 하지 않았다.

## 재현 가능한 생산 및 게시 결과

- `source/build_r36hw_n17.cjs` — Node.js만 사용하는 중심부 메시 생산기
- `output/R36HW_N17_CENTER_DEPTH.glb` — GitHub Actions가 실제로 생성한 GLB
- `reports/R36HW_N17_CENTER_DEPTH.json` — 원본/산출 SHA-256, 변형량, 구조 검사
- `../r36hw-n17-center-render-20261129/output/` — 실제 GLB를 렌더한 총 12개 캡처(일반 중심부 6장 + 수정 대상 골반 primitive 3만 분리한 6장)

재현: `node experimental/xpz3d/f11/r36hw-n17-skin-field-20261129/source/build_r36hw_n17.cjs`.

## 실제 수정값

- 전체 **2,099삼각형**, 골반 **363삼각형**, 63본 유지
- 중앙 골반 정점 **94개** 실제 위치 변화, 원본 노출 경계 45개 고정
- 최대 정점 이동 **18.863mm**. 정점 평균 절대 이동 약 2.796mm
- 비대칭 홈·융기 프로파일과 18차 조화평활 기저 표면을 국소 적용
- 삼각 면 반전 0, 입력/출력 SHA-256 기록
- 기존 얼굴/헤어 및 골반 외의 primitive, UV, JOINTS_0, WEIGHTS_0 미변경

## 자체 피드백: 시각적 실패 원인

원래 모델과 N17의 정면 CLAY 캡처에서 중심부 윤곽과 큰 삼각형 패턴이 거의 변하지 않는다. 골반 primitive 3만 분리한 캡처에서도 동일한 패턴이 나타나므로, **다른 메시의 가림만으로 설명할 수 없다.** 현재 N16에서 상속한 의복형 대형 패널과 골반의 구조 자체가 원인 후보이며, 작은 중심 정점의 Y 깊이 변화/법선/UV로는 해결되지 않는다.

**형상 및 미술 합격 미달**. 이 GLB를 최종 목표 사진 재현으로 취급하면 안 된다. 다음 단계는 원본 63본/외부 경계/예산을 유지하는 가운데, 기존 큰 의복형 면을 국소 삭제하고 피부형 곡면 토폴로지로 교체하는 것이다. 단순 스무딩·재질 보정 반복 금지. 네이티브 S2 렌더 및 실시간 63본 스키닝은 별도 미완료.

렌더러는 실제 GLB 입력을 쓰는 Node CPU 진단용이며, 네이티브 S2 결과가 아니다.
