# R36HW F11 V19 — minimal matte bronze sportswear

A V17-derived alternate outfit without the V18 chevron, stripe or emblem. Smooths garment vertex color in welded adjacency while preserving collar, cuffs and ankle trim. Muted bronze, opaque matte material and subtle textile normals distinguish the garment. Geometry, skeleton, weights, UVs and original textures remain unchanged. No added anatomical markings.

Reproduce: `node source/build.cjs /path/to/V17.glb`. Exact input hash, unchanged geometry/rig checks and color-smoothing metric are included. Native S2 and visual rendering have not been tested. The numeric metric is not proof of visual quality.
