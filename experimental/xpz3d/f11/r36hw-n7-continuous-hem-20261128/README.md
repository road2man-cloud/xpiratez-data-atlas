# R36HW N7 — 연속형 의복 하단 보정 및 중심부 정점 완화

## N6 대비 실제 수정
- N6 CLAY 전면 확대 PNG에서 하부 삼각형들이 톱니처럼 돌출되는 현상이 확인되어 **N6 외관 승인 보류**.
- 원인으로 관찰된 `abs(x)>0.067` 절벽형 폭 보정 조건을 제거하고 `smoothstep`과 `tanh`를 이용한 **연속형 폭 보정**으로 교체.
- R36HW 원본 바지 primitive의 92개 좌표와 N3에서 추가한 중심 정점 82개를 원본 인덱스로 다시 구성. 중심 정점은 변형된 부모 삼각형 면에 가까워지도록 56% 제한 보간.
- 얼굴·머리카락·본 구조, N5 피부 경계 메시, N4 피부 컬러·미세 노멀 GLB 내용은 유지. R36JB 몸체는 사용하지 않음.
- 총 삼각형 **2,080개 유지**. 정확한 변형량은 GitHub Actions가 만든 JSON 보고서를 참조.

## 재현 실행

```bash
node experimental/xpz3d/f11/r36hw-n7-continuous-hem-20261128/source/build_r36hw_n7.cjs
```

입력: N5 GLB, R36HW 원본 GLB, N3 중심 정점 보고서.
출력: `output/R36HW_N7_SOFT_HEM.glb` 및 `reports/R36HW_N7_SOFT_HEM.json`.

## 남은 한계
- 하단의 닫힌 의복형 메시를 **완전한 피부 토폴로지로 교체한 것은 아님**.
- 원본에 없던 가려진 피부를 포토그래메트리 수준으로 복원하지 않았음.
- 네이티브 S2 UV/노멀 및 실제 63본 실시간 스키닝 미구현.
- N7의 메시 렌더가 N6보다 나은지 실제 PNG 확인 전에는 시각적 합격이라고 주장하지 않음.
