# R36HW-N14 — 중심부 세 정점 패치 (실제 GLB 제작)

## 실제 완료

N13 원본 R36HW 계열 골반 primitive의 중앙 32번 정점에는 **40개** 삼각형이 연결되어 있었다. N14는 이 정점을 세 개로 나누어 기존 40면을 **13·18·9면 세 구역**에 분배하고, 사이에 이음매 삼각형 3개와 중앙 1개를 추가했다.

- 전체 **2,099삼각형** (N13 2,095 → N14 2,099)
- 골반 정점 **238 → 240개**
- 분리한 중심 정점 연결 차수 **16·21·12**
- 원래 골반 외곽 경계와 원본 63본 구조 유지
- 원본 얼굴·머리카락/외부 primitive 미수정
- 기존 골반 primitive에 직접 통합한 연결형 패치; 부유 장식/이미지 투영 없음
- 첫 시도는 기존 면 2개가 반전되어 실패. 자동 오프셋 축소를 적용해 **이동 배율 0.5**에서 성공

## 재현

```bash
node experimental/xpz3d/f11/r36hw-n14-three-pole-center-20261129/source/build_r36hw_n14.cjs
```

결과 `output/R36HW_N14_THREE_POLE_CENTER.glb`, `reports/R36HW_N14_THREE_POLE_CENTER.json`.

진단 화면 `../r36hw-n14-center-render-20261129/output/`: 실제 GLB 기반 정면/사선/측면 중심부 CLAY·SHADED 6장. **네이티브 S2 캡처가 아님.**

## 미완료와 다음 우선순위

실제 N14 정면 및 사선 캡처에서 과도한 뾰족 음영이 남고, 골반 외부 윤곽이 반바지형이다. 사용자 사진의 부드러운 비대칭 굴곡에는 아직 도달하지 못했다. **미술 합격 불가.** 추가 전신 작업은 금지하고 중심부 형상과 실제 인접면의 깊이/노멀 연속성, 그리고 의복 유래 패치의 제한적인 교체에 집중한다. 남은 2,100 예산은 한 삼각형뿐이므로 새 중심부를 상세하게 만들려면 비핵심 국소면의 안전한 회수와 재배치가 필요하다.
