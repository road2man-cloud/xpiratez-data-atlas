## 구현 변경

`build_r36kx.py`는 R36KW의 70개 패치 메타데이터를 고정 SHA-256으로 확인한 뒤, 몸통 쪽 56개 영역을 가느다란 3열로 옮기고 헤어 14개 영역을 원본 이미지 옆과 아래로 옮긴다. 원래 몸통 N×N 픽셀, 원래 헤어 픽셀과 좌우 여백, 70개 패치의 모든 픽셀을 그대로 복사한다. 재샘플링/노멀 재생성/재베이크는 없다.

변경된 속성은 primitive `1,7,8,9,10,11`의 `TEXCOORD_1`뿐이다. 위치, 법선, 탄젠트, 색상, 기존 색상 UV, 관절 인덱스와 가중치, 인덱스 배열, 정점 수를 그대로 유지했다. 재질, 샘플러, 본 계층, inverse-bind 행렬과 노드도 보존했다. 공유 정점이 서로 다른 이동 영역에 걸리면 자동 덮어쓰기 대신 빌드를 중단한다.

이미지 9장 중 7장은 바이트 단위로 동일하다. 몸통 노멀과 헤어 노멀의 PNG 크기 및 배치만 바뀌었다. 이미지 정보를 기록하는 메타데이터와 GLB 접근자 번호는 재패킹으로 달라질 수 있다.

## 표현 보존의 정확한 범위

기본 해상도의 픽셀 값은 그대로지만 UV는 float32이므로 좌표 환산에 아주 작은 반올림 오차가 있다. 삼각형 꼭짓점·모서리·내부 총 14,250개 샘플에서 기본 양선형 색값 차이는 각 채널 기준 최대 0.000184/255 미만이었다. 이것을 모든 가능한 화면 픽셀의 수학적 동일성 증명으로 부르지 않는다.

크기가 바뀐 이미지로부터 자동 생성되는 **밉맵은 동일하지 않다.** 비교 HTML은 노멀 텍스처 필터를 원본 밉 방식과 기본 해상도 방식으로 바꾸어 그 차이를 확인할 수 있다.

실제 headless Edge / three.js r170 / WebGL2 / file:// 비교에서는 모델 4개가 로드되고 JavaScript 오류가 없었다. 두 해상도 전신 색상 전용 캔버스는 RGB 차이 0, 선택한 14개 PBR 비교 장면은 최대 채널 차이 1/255였다. 원거리 시점도 포함한다. 이것은 해당 시점·조명·합성 포즈에 한정한다. HTML의 GLB 내보내기도 생산 GLB와 바이트 대조를 통과했다.

## 호환성과 미완료

새 노멀 이미지는 NPOT다. 대상 렌더러가 NPOT 밉맵을 지원하고 임의로 큰 정사각형으로 늘리지 않아야 계산한 면적 절감이 유지된다. 이번에 실제 실행한 것은 WebGL2 뷰어이며 **S2/S3의 NPOT 처리와 실제 VRAM 절감은 미확인**이다. 기존 R36KW GLB를 비교/호환성 대안으로 그대로 보관한다.

S2/S3 설치폴더 적용, 실제 전투 애니메이션, GPU 메모리/FPS 측정, 몸통–다리의 위상 접합, 고밀도 원본 확보·복원은 하지 않았다. 기존 게임 폴더와 다른 작업자의 프로젝트는 변경하지 않았다. GitHub 업로드는 Pages 배포나 게임 배포와 별개다.
