# R36ME — 기존 2,100 삼각형의 물리 밀도 재배치

R36MC의 정점 조형은 실제로 입체를 바꾸었지만 삼각형 간격은 그대로였다. R36ME는 **실제 구조 윤곽곡선 가까이 기존 물리 정점들을 X/Z 방향으로 이동**해 중앙의 실질 삼각형 밀도를 조절한다. UV 분할 복제 정점은 함께 이동하며 전체 2,100△(몸체 1,132 + 기타 968), 63본 골격, 본 인덱스와 웨이트는 유지한다.

- `source/build_r36me.cjs`: 원본 정점 좌표별 그룹화, 구조 윤곽과 가장 가까운 곡선 계산, 이동 후 면적비/법선 방향 점검, 왜곡이 크면 이동 강도를 단계적으로 감소, 노멀/탄젠트 재계산
- `.github/workflows/xpz3d-r36me-density.yml`: Node.js 22 자동 생산, ART/SUBTLE×DENSE/GUARDED 4종 GLB
- `output/<VARIANT>/R36ME_<STYLE>.report.json`: 실제 이동 물리 위치/복제 UV 정점 수, 곡선에 가까워진 정도, 최소 면적비, SHA-256

**작업을 정확하게 구분해야 한다.** 이 버전은 삼각형의 간격과 면적을 바꾸는 **물리 정점 재배치**지만, 삼각형의 연결을 끊고 다시 이어 붙이는 **새 리토폴로지**는 아니다. 실제 엣지 플립이나 새 토폴로지와 함께 스킨의 외관을 보존하는 작업은 아직 남아 있다.

재배치된 GLB에 기존 텍스처를 그대로 사용할 때에는 3D 곡면과 이미지 디테일 방향을 별도로 확인해야 한다. 단색 CLAY 결과가 목표 형상에 근접하지 않는다면 재질 변경으로 대신하지 않는다.
