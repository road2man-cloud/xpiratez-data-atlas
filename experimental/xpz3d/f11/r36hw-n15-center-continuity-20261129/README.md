# R36HW-N15 중심부 곡률 연속화 — 실제 제작 결과

R36HW → N14의 몸체를 그대로 계승하고 **중심부만** 수정했다. N15는 이미지 생성이 아닌 실제 GLB 메시 개조다. R36JB 몸체를 가져오지 않고 전신을 다시 조형하지 않았다.

## 실제 산출물

- `source/build_r36hw_n15.cjs`: Node.js 생산기
- `output/R36HW_N15_CENTER_CONTINUITY.glb`: 중심부 기존 정점 위치와 법선 재조정 모델
- `reports/R36HW_N15_CENTER_CONTINUITY.json`: 원본·산출물 해시, 변경량 기록
- `../r36hw-n15-center-render-20261129/output/`: 실제 GLB를 사용한 정면/사선/측면 중심부 CLAY/색상 진단 6장

## 이번 변경

- 전체 2,099삼각형, 골반 363삼각형 유지. 기존 중앙 3정점 연결 패치 유지.
- 중심부 정점 89개를 대상으로 여섯 차례 곡률 완화와 완만한 비대칭 국소 주름 변위를 적용.
- 골반 외곽 경계 45개 정점의 좌표 유지.
- 첫 시도에서 면 1개가 반전되어 실패. 기존 면의 법선 방향을 유지하도록 이동량 자동 감쇠 기능을 추가한 후 재생산.
- 감쇠 배율 0.5, 최대 정점 이동 4mm, 실제 면 반전 0개, 원본 63본 및 얼굴·머리카락 변경 없음.
- 사용자가 첨부한 이미지는 기하 형태의 질적 참고 자료로만 사용. 원본 사진 투영/텍스처 사용 없음.

## 자체 미술 품질 평가

근접 CLAY의 중앙에는 여전히 매우 날카로운 삼각 음영과 의복 유래 측면/하단 형상이 나타난다. **N15는 원본 메시 곡면 완화 시제품이지 목표 이미지에 도달한 완성품이 아니다.** 스무딩 수치나 법선 변경만 반복하는 방식은 해결책이 아님이 재확인됐다.

다음 개발은 원본 몸체의 결합부를 보존하는 조건에서 중앙부의 큰 삼각면을 부분 재구성하고, 의복 유래 골반 표면과 실제 피부 메시의 연결을 개선해야 한다. 네이티브 S2 PBR 및 스키닝 품질은 미확인.
