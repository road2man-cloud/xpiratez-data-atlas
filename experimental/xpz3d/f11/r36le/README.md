## 보정 방법과 자체 피드백

초기 DQS 근사 후보는 일부 모서리의 최대 왜곡이 악화되어 채택하지 않았다. 최종본은 실제 메시에서 허벅지/종아리의 영향이 섞인 국소 정점을 선택하고, 45도 및 90도 자세에서 모서리 길이의 로그 변형량과 보정 크기 정규화 항을 최소화하는 제한된 최소제곱 문제로 정점 보정을 산출한다. 동일 위치와 영향 가중치를 가진 중복 정점은 함께 움직인다. 90도 최대 보정 크기는 왼쪽 0.019775, 오른쪽 0.019926 모델 단위다. 법선 및 탄젠트 방향은 인접 면의 기하 법선 변화로 근사하며 실제 렌더에서 개선되었다고 단정하지 않는다.

| 무릎 굽힘 | 왼쪽 RMS 로그 변형 전→후 | 오른쪽 RMS 로그 변형 전→후 |
|---|---:|---:|
| 30도 | 0.06495→0.05839 | 0.06486→0.05831 |
| 45도 | 0.08984→0.06958 | 0.08964→0.06943 |
| 60도 | 0.10880→0.08019 | 0.10847→0.07999 |
| 90도 | 0.14373→0.08533 | 0.14328→0.08496 |
| 95도 | 0.15125→0.08915 | 0.15083→0.08877 |

90도에서 RMS 로그 길이 변형 약 40.6~40.7% 감소. 95도는 타깃 생성 각도가 아닌 별도 검사 각도다. 이 값은 모델의 국소 단축/늘어남에 대한 CPU 계산 지표로서 실제 부피나 시각적 품질, 게임 엔진 결과를 의미하지 않는다. 후보 강도 선택에 검사 각도 결과도 사용했으므로 통계적으로 독립적인 일반화 검증이라고 표현하지 않는다.

## 외부 모션의 가중치 적용
각 무릎의 기본 회전 대비 로컬 X축 굽힘 각도 a를 0~90도로 제한한다. 0~45도에서 (w45,w90)=((a/45)^2,0), 45~90도에서 (1-t,t), t=(a-45)/45. 기본값은 0,90도 초과는 90도 타깃으로 제한한다. 기존 내장 8개 애니메이션에는 가중치 트랙이 생성되어 있다. 외부 게임 모션은 해당 엔진에서 동일한 제어 로직을 구현하거나 별도로 가중치를 베이크해야 한다. glTF 모프와 가중치 채널의 S2/S3 지원은 아직 미확인이다.

## 재생산
Python 3.9 이상, numpy, scipy, Pillow. 입력 GLB가 없으면 python prepare_r36le.py. python build_r36le.py로 두 산출물 및 보고서를 제작한다. python publish_r36le.py는 ZIP 생성, --publish는 인증된 gh로 새 GitHub 경로에 업로드한다. 기존 버전을 덮어쓰지 않는다.

제작 경로 C:\mnt\data\r36le_work. 이전 내부 컨테이너의 DNS 제한을 고려해 이번에도 격리 Windows 작업공간을 사용했다. 게임 설치폴더를 변경하지 않았다. 실제 S2/S3 로딩/렌더링, 조명에 따른 법선 효과, 관절의 완전한 위상 접합은 미완료다. 폴리곤이나 기본 텍스처를 새로 생성한 버전은 아니다. 다음 단계는 엔진 호환성 및 실제 모프 재생을 확인하고, 필요시 모프를 지원하지 않는 엔진용 대안 변형 방식을 구현하는 것이다.
