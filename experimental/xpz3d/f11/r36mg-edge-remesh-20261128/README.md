# R36MG — 실제 메시 연결 재구성 및 삼각형 UV 이미지 재투영

## 목적

R36MF까지는 몸체 1,132개 삼각형의 물리 정점을 움직이고 이미지 정보를 구조별로 나누었지만, **삼각형이 서로 연결되는 물리적 모서리는 바꾸지 않았다.** R36MG는 R36MF의 몸체에서 실제로 두 삼각형 사이의 공유 대각선을 다른 대각선으로 교체하는 `2-to-2 edge flip`을 구현한다.

연결이 바뀐 폴리곤의 원래 2048 컬러/노멀 이미지 정보를 원래 두 삼각형의 표면에서 다시 샘플링해 해당 UV 타일에 기록한다. 새 이미지를 대량 생성해 덧칠하는 것이 아니라 원본 이미지의 대응 픽셀을 다시 매핑하는 방식이다.

## 파일

- `source/build_r36mg.cjs`: 후보 물리 공유 모서리 검출, 모서리 기준 두 삼각형의 대각선 교체, 기하 안정성/투영 가능성 검토, 원본 정점에서 본 인덱스·가중치·법선·탄젠트를 새 UV 슬롯으로 할당, 새 텍스처 베이크
- `.github/workflows/xpz3d-r36mg-edge-remesh.yml`: GitHub Actions Node.js 22; ART·SUBTLE × DENSE·GUARDED 4종 GLB + CLAY 4종, PNG, JSON 생성
- `preview/index.html`: R36MF ↔ R36MG를 정면(-Y), 35°, 측면에서 CLAY 또는 이미지 재질로 비교
- `output/<VARIANT>/R36MG_TOPOLOGY.report.json`: **실제 선택된 엣지 플립 수, 변경된 삼각형 ID와 품질, 재투영 픽셀 수, SHA-256** 기록

## 변경을 정확하게 표현

- 전체 2,100삼각형(몸체 1,132 / 얼굴·헤어 968), 63본을 유지한다.
- 이 작업은 실제 **삼각형 사이의 연결을 변경**한다. R36ME의 단순 위치 이동과 다르다.
- 엣지 플립은 면적, 투영 사각형의 볼록성, 연결성, 원래 면 법선과의 일치 조건을 만족하는 경우에만 적용한다.
- 재연결한 삼각형은 원래 UV 슬롯을 유지하되, 원본 표면에서 컬러·노멀을 다시 추출한다. 본/웨이트는 각 새 물리 꼭짓점에 맞춰 함께 이동한다.
- 원래 머리·헤어, 본 계층, 애니메이션, 다른 장비 자산은 변경하지 않는다.
- **삼각형을 추가하거나 없애는 부위 간 예산 재배분은 별개의 과제다.** 이 버전은 실제 *엣지 연결* 수정이다.

## 완료 상태 판단

GitHub에 코드 파일이 게시된 사실만으로 실제 GLB 생산 완료라고 하지 않는다. 빌드가 성공했다면 `output/compact/` 실제 GLB와 `R36MG_TOPOLOGY.report.json`에서 플립 개수(0보다 커야 함), 원본 삼각형 수, 재투영 픽셀 수를 확인한다.

CLAY 상태에서 사진과 유사하지 않다면 형상 가설은 실패이며 UV 재질 증가만으로 승인하지 않는다. 실제 단색 렌더 및 S2 게임 엔진 QA, 형상 승인 또한 별개다.
