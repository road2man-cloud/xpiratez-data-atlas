# R36LT — 실제 이미지 기반 UV 디테일 투영 생산기

이 단계는 **명암 스트로크가 아니라 외부 RGBA PNG의 실제 픽셀을 기존 2048 UV 컬러 아틀라스에 투영**한다. R36LS GLB를 그대로 입력으로 쓰며 2,100 삼각형(몸체 1,132 / 얼굴·헤어 968), 63본, UV, 웨이트, 기존 노멀/ORM을 보존한다. 참조 이미지를 직접 GLB에 평면 스티커로 붙이는 것이 아니라 바인드 공간의 몸체 삼각형을 통해 UV로 역투영한다.

```bash
node source/build_r36lt.cjs \
  ../r36ls-illustrated-skin-20261128/output/compact/R36LS_ART_2100_COMPACT_FULL.glb \
  reference_rgba.png config.example.json output/r36lt
```

**중요:** 참조 PNG는 투명 배경의 직립/정렬된 디테일 패치여야 한다. 예시 설정의 좌표는 임의의 초기 투영 영역으로, 정확한 바인드 좌표는 실제 GLB의 해당 부위와 맞춰 교정해야 한다. 이미지의 원본 회전/원근은 이 생산기가 자동으로 추정하지 않는다. 원본 사진을 저장소에 무단 게시하지 않는다. 원본 참조 이미지 없이 GLB 생성 성공을 주장하지 않는다.

`bounds`의 xMin/xMax/zMin/zMax는 GLB **바인드 공간 좌표**이며 zMax가 패치의 위쪽이 된다. `frontY`와 `frontDirection`으로 반대쪽 신체 표면에 투영되는 것을 차단한다. `edgeFeather`는 패치 외곽의 경계를 자연스럽게 섞으며, 알파는 참조 이미지가 정의한 실제 형상을 유지한다.

현재 생산 범위는 **albedo** (실제 그림 파일)의 입히기다. 뒤이어 해당 텍스처와 일치하는 tangent-space normal/height를 이미지에서 별도로 베이크하고, 시각 검토 후 제한적 메시 곡률 수정을 실시한다. 해당 작업은 아직 완료로 표시하지 않는다.

실행 경로는 R36LS와의 상대 경로를 정확히 맞춰야 한다. 위 CLI는 이 디렉터리에서 실행한다고 가정한다.
