# R36MF — 기하학적 정점 밀도 보정 + 구조별 UV 텍스처 + CLAY 검사용 통합 후보

## 작업의 정확한 의미

이 버전은 세 개의 실제 생산 단계를 하나의 전신 GLB로 합친다.

- **R36MC**: 사진 구조에서 추정한 8개 조절 가능한 윤곽을 따라 실제 X/Y/Z 정점을 이동하여 비대칭 곡면 형상 제작
- **R36ME**: 기존 2,100삼각형의 3D 정점 위치를 구조 경계 가까이 재배치; 본/웨이트/UV/삼각형 연결은 유지
- **R36MD**: R36ME의 새로운 3D 정점 위치를 기준으로 기존 R36MB 이미지 노멀을 탄젠트 공간에 재정렬하고, 실제 구조 8개 영역의 컬러·노멀·마스크 PNG를 분리하여 전체 GLB 생산
- **R36MF**: R36MD 생산 결과에서 색상/노멀 텍스처를 완전히 제거한 단색 CLAY 전신 GLB를 함께 생산

새 이미지를 전체 표면에 덮어씌우지 않으며, 사진의 색상 차이를 실제 깊이의 측정값으로 취급하지 않는다. 시각적 형태와 재질은 별도로 평가해야 한다.

## 실제 소스·워크플로

- `source/create_clay.cjs`: 기존 스킨/정점/애니메이션을 유지한 채 모든 메시의 재질을 단색 무광으로 대체하여 CLAY 모델 제작
- `.github/workflows/xpz3d-r36mf-integrated.yml`: GitHub Actions Node.js 22, `R36MD` 이미지 재베이크 생산기를 R36ME 조형 입력에 적용, ART/SUBTLE × DENSE/GUARDED 4개 조합에 대해 컬러/노멀과 CLAY 전신 GLB 생산
- `output/compact/R36MF_<MODEL>_<STYLE>_2100_COMPACT_FULL.glb` (실제 텍스처)
- `output/compact/R36MF_<MODEL>_<STYLE>_CLAY_2100_COMPACT_FULL.glb` (단색 형상)
- `output/<MODEL>_<STYLE>/R36MD_SEMANTIC.report.json` 및 구조별 PNG 패치

## 미완료 / 가설을 무효화하는 조건

- 사진 1장만으로 3D 깊이와 감춰진 면을 정확하게 측정할 수 없다. 랜드마크는 목표 형상 가설이다.
- 단색 CLAY 모델에서 구조적 윤곽과 중첩 정도가 목표와 다르면 **형상 가설 실패**다. 텍스처 양을 늘려서 외관 성공으로 취급하지 않는다.
- 실제 엣지 재연결을 포함한 **리토폴로지와 부위 간 신규 삼각형 재배분은 미완료**. 기존 정점의 공간적 재배치까지 구현했다.
- S2 엔진 및 브라우저의 실제 화면이 아직 승인되지 않았다. GLB가 생성되고 모델 수치가 맞아도 미술적 목표 달성이라는 뜻이 아니다.
- 최종 파일 생산 및 GitHub 게시 여부는 해당 Actions run과 `output/compact/` 실제 파일 확인을 기준으로 보고한다.

기본 시각 평가용 뷰어는 `../r36mc-landmark-sculpt-20261128/preview/index.html`이며 Z-up / 전면 −Y 카메라를 적용한다. R36MF와 직접 비교하기 위해서는 뷰어 입력 모델만 이 버전의 GLB로 연결하면 된다.
