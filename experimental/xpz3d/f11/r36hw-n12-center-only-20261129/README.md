# R36HW N12 — 중심부만 골반 메시 안에서 조형

기준: R36HW 원본 계보 N11 GLB. 전신 조형/리모델링을 하지 않고 기존 골반 primitive의 중앙만 조형한다.

- 14개 정성적 구조 랜드마크로 비대칭 중심 홈 및 접힘·융기 프로파일을 생성함. 단일 사진을 GLB에 삽입하거나 UV로 붙이지 않음.
- 원래 골반 삼각형 55개를 각 3면으로 분할하여 중심 정점 55개를 추가함. 전체 1,985 → **2,095삼각형**, 기존 63본 유지.
- 원래 골반 메시의 기존 정점·면과 공유하여 별도 부유 구조를 생성하지 않음. 신규 정점 UV와 본 가중치는 기존 삼각형에서 보간.
- 열린 허리·다리 경계 45개 정점 고정. 기존 정점 중 35개 수정, 최대 이동 9.5mm.
- N12 CLAY 근접 캡처에서는 중심에 별형 삼각 면 패턴이 남음. **사진의 외관에 도달하지 못했음.**
