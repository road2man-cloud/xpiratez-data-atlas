# R36HW N13 — 중심부 토폴로지 방향 교정

N12의 실제 GLB 기반으로 **정점 수·실루엣·전체 2,095삼각형**을 유지하면서 중앙 인접 삼각형 간의 내부 에지를 재연결한다.

- 중심부 내부 에지 플립 48건. 굴곡을 변경할 경우 두 삼각형의 방향과 투영 영역의 볼록성을 제한함.
- 선택된 국소 149삼각형 중 품질 점수 0.3 미만인 긴 삼각형: **57 → 23개**. 이는 면비율 지표이며 미술 품질 승인값이 아님.
