## 실제 발 메시 기반 보정

양쪽 발 각각에서 중복 제거한 정점 20개와 바닥 근처 지지 정점 10개를 선정한다. 본별 역바인드 행렬과 선형 혼합 스키닝으로 변형된 발 위치를 계산하고, 정지 자세의 최저 높이(약 0.036 모델 단위)를 평지 기준으로 삼는다. 각 키프레임에서 뒤꿈치/중앙/발끝 지지점 혼합과 최저 높이를 목표로 허벅지, 무릎, 발목의 IK를 다시 푼다. 기하/UV/스키닝 가중치 자체는 변경하지 않는다.

## 자체 피드백 및 정량 결과

첫 빌드는 평평한 발의 접지점만 재보정했다. 이미 R36LB의 평발 모션도 실제 발 정점 계산에서 접지가 거의 정확했으므로 그 빌드를 최종 산출물로 채택하지 않고 굴림 동작을 추가했다.

R36LB 평발 모션의 발 각도 범위는 사실상 0도다. R36LC는 -12~+18도 구간을 추가한다. 계산한 입각 구간 최저 발 높이 오차: 저장된 73개 시점에서 R36LB 최대 2.56e-8, R36LC 최대 6.55e-9 모델 단위. 키 사이를 포함한 289개 시점에서는 각각 1.8795e-5, 5.3969e-5 모델 단위다. 굴림을 추가해 보간 오차는 증가했다. 계산한 굴림 지지점 목표 오차는 289개 시점 기준 최대 2.802e-5 모델 단위다. 지지점 자체가 뒤꿈치에서 발끝으로 이동하는 것은 의도이며 고정점 미끄러짐 수치와 혼동하지 않는다. 이 수치는 CPU 스키닝 및 쿼터니언 보간의 결과이며 실제 엔진 렌더링 또는 물리 접촉의 측정값이 아니다. 선택된 발 영역의 바닥 접지 모델이며 전신 충돌, 개별 발가락 굽힘, 경사/계단 IK는 구현하지 않았다.

## 사용 및 재생산

제자리 클립은 외부 오브젝트 전진 속도 0.5 모델 단위/초가 필요하다. RootMotion 클립은 골반에 한 주기 0.60 모델 단위의 이동이 내장되어 있으므로 외부 이동을 중복 적용하지 않는다. 엔진의 누적 root-motion 처리 없이 단순 반복하면 위치가 되돌아간다. 모델 단위와 실제 게임 월드 단위 변환은 확인되지 않았다.

Python 3.9 이상, numpy, scipy, Pillow. 입력 GLB는 번들에 포함되며 없으면 python prepare_r36lc.py로 고정 커밋에서 다운로드한다. python build_r36lc.py를 실행하면 신규 GLB와 보고서, 289개 보간 시점의 발 접지 추적 JSON이 생성된다. python publish_r36lc.py는 묶음을 만들고 --publish 지정 시 새 GitHub 디렉터리에 게시한다. 기존 버전은 덮어쓰지 않는다.

작업 위치 C:\mnt\data\r36lc_work. 기존 게임 설치 폴더를 변경하지 않았다. 실제 S2/S3 로딩, 전투 애니메이션, 런타임 IK 및 관절 외관 검토는 미완료다.
