# R36MA — R36LZ 실제 곡률과 UV 이미지 경계 일치화

## 작업 목적

R36LZ에서는 편집용 OBJ → 2,100삼각형·63본 전신 GLB의 왕복과 정점/노멀/탄젠트 갱신이 구현되었다. 그러나 **실제 이미지 아틀라스의 분리된 UV 경계는 이전 픽셀의 색상과 탄젠트 노멀 방향을 유지**하므로 화면에서 외관 단절을 만들 수 있다.

R36MA는 전신 모델의 원래 표면을 유지한 채 **실제 3D 공유 모서리에 대응하는 양쪽 UV 차트의 경계 픽셀**을 보정한다. 사진 전체를 면으로 펴서 덮거나 새 명암 브러시를 그리지 않는다.

## 구현물

- `source/build_r36ma.cjs`: 3D 정점 위치 기반 공유 모서리 검출, UV가 분리된 실제 모서리 선별, 면 법선 차이/기존 텍스처 노멀 방향 검사, 소량의 색상 보정 및 노멀의 모델 좌표 변환/재투영, 원본 아틀라스의 UV 외곽 여백 4px 재생성.
- `.github/workflows/xpz3d-r36ma-seam-rebake.yml`: Node.js 22로 `R36LZ_*_COMPACT_FULL.glb` 4종 입력, ART·SUBTLE×FLOW·GUARDED 출력, Github Actions 아티팩트 및 `main` 산출물 게시.
- 출력은 `output/<MODEL>_<STYLE>/R36MA_SEAM_COLOR_2048.png`, `R36MA_SEAM_NORMAL_2048.png`, `R36MA_SEAM_REBAKE.report.json` 및 `output/compact/R36MA_<MODEL>_<STYLE>_2100_COMPACT_FULL.glb` 구조.

## 기술적 제약

- 원본 2048 컬러·노멀 텍스처에서만 픽셀을 샘플링하고, **UV 경계 안쪽 최대 6px** 근처에서만 섞는다. 내부 이미지 디테일은 건드리지 않는다.
- 월드(실제로는 모델 바인드 공간) 방향으로 기존 노멀을 비교하고, 서로 다른 UV 차트의 탄젠트 공간으로 되돌려서 저장한다.
- 선행 R36LZ 모델의 몸체 1,132삼각형, 얼굴·헤어 968삼각형, 63본, 스킨 가중치·원본 UV·실제 정점 위치는 수정하지 않는다.
- 양쪽 공유 물리 모서리가 2개 면에만 대응하는 경우에 한정하며 비정상 연결 또는 급격하게 꺾인 모서리는 수정하지 않는다.
- 각 삼각형의 법선·탄젠트가 기존 GLB에 존재해야 한다.
- 수정된 이미지에 맞춰 UV 차트 바깥 여백 4px를 갱신하고, 결과 보고서에 실제 변경 픽셀과 처리한 공유 경계를 기록한다.

## 실행

```bash
BASE=experimental/xpz3d/f11
ROOT=$BASE/r36ma-seam-rebake-20261128
node "$ROOT/source/build_r36ma.cjs" \
 "$BASE/r36lz-cage-roundtrip-20261128/output/compact/R36LZ_ART_FLOW_2100_COMPACT_FULL.glb" \
 "$ROOT/output/ART_FLOW" 6
```

**상태 분리**: 이 문서의 코드·워크플로 게시와 실제 산출물 게시 및 외관 품질 승인은 다른 단계다. 성공한 빌드의 `*.report.json`과 GitHub `main` 트리를 확인하기 전까지 모델 생산 성공으로 기록하지 않는다. 입력 영상·사진의 실제 깊이를 추정한 것이 아니며 S2 게임 엔진 투영·목표 이미지 비교도 아직 완료되지 않았다.

## 다음 작업

경계 이미지 보정 후에도 거친 삼각형 조형이 보이면 제한된 2,100삼각형에서 기존 정점 재배치 또는 폴리곤 예산 재분배가 필요하다. 색채/노멀 변화량의 증가만을 미학적 성공으로 오인하지 않는다.
