## 추가 애니메이션

| 이름 | 길이 | 샘플 | 기능 |
|---|---:|---:|---|
| F11_Walk_Contact_InPlace | 1.2초 | 73 | 골반 수평 이동 없는 반복 걷기. 외부 이동을 -Y 방향 0.5 모델 단위/초로 제공할 때 접지 기준점 고정 |
| F11_Walk_Contact_RootMotion | 1.2초 | 73 | 골반 본에 -Y 방향 0.60 모델 단위 전진을 포함한 걷기 |

각 클립은 17개 채널, 초당 60개 샘플 간격이다. 골반 수직 위치, 양쪽 허벅지/무릎/발목/발가락 회전을 두 링크 IK로 계산하고 상체의 기존 걷기 채널은 보간해 재사용한다. 엔진 좌표 변환 노드는 보존한다. 입각 비율 7/12, 좌우 위상차 0.5, 발목 목표 들림 0.095 모델 단위, 골반 기본 하강량 0.065 모델 단위. 원본 게임 걷기 동작 복원이 아닌 합성 모션이다.

RootMotion은 골반 본에 이동이 들어 있으므로 캐릭터 오브젝트를 동시에 같은 속도로 전진시키면 이중 이동이 생긴다. 엔진에서 반복 재생할 경우 끝점의 0.60 모델 단위 이동을 다음 주기에 누적해야 한다. 단순 반복 재생은 위치가 되돌아간다. InPlace는 외부 이동이 없거나 다른 속도일 경우 발목이 미끄러질 수 있다. 게임 월드 단위 환산과 엔진의 root-motion 추출 방식은 미확인이다.

## 생산 단계 자체 점검

R36LB_CONTACT_TRACKS.json에 73개 샘플별 발목 목표/계산 위치 및 같은 가상 전진 속도를 적용한 R36LA의 계산 위치가 있다. 원본 R36LA에 새 동작과 동일한 가상 전진 속도와 입각 구간을 가정했을 때 최대 발목 기준점 이탈은 좌우 약 0.481 모델 단위였다. 신규 두 클립의 해당 값은 0.00000005 모델 단위 미만이다. 새 목표의 최대 오차도 0.00000005 미만이었다. 이는 고정된 발목 기준점의 샘플 계산값이며 실제 게임이나 렌더링에서 측정한 값이 아니다. 발바닥 메시 전체의 접촉, 프레임 사이 보간, 지면 높낮이, 충돌 및 외관의 자연스러움은 검증하지 않았다.

## 재생산
Python 3.9 이상, numpy와 Pillow. 입력 파일은 ZIP에 포함된다. 필요한 경우 python prepare_r36lb.py, 이후 python build_r36lb.py. python publish_r36lb.py로 패키징한다. --publish는 authenticated gh 사용 및 GitHub의 새 버전 경로에 게시하는 명시적 옵션이다. 기존 버전은 덮어쓰지 않는다.

작업은 C:\mnt\data\r36lb_work 격리 Windows 작업공간에서 수행했다. 게임 실행폴더는 변경하지 않았다. S2/S3 로딩, 전투 모션, 실제 지면 IK, 렌더 비교는 미완료다. 후속 작업은 애니메이션 플레이어에서 발바닥 메시 접촉과 관절 외관을 확인하고 지형 대응/클립 전환을 구현하는 것이다.
