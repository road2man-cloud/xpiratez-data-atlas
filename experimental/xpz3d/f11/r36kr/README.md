# XPZ3D R36KR — 실제 생산 및 인계

2026-11-27, source-locked R36KQ → R36KR. 분리된 **R36KK-SEAM-V3** 계보를 R36KR로 부르지 않습니다.

## 실생산 현황

- 정확한 입력: R36KQ 1024 / 512 GLB (SHA-256 사전 검사).
- 출력: R36KR 1024 / 512 GLB, 2,100△, 63 bones.
- 허벅지 프리미티브 10/11의 상단 접합 정점 및 아래쪽 전이 대역만 수정.
- 위치·법선 및 **Hip/Thigh 스키닝 가중치** 수정. 얼굴/헤어/손/몸통 및 텍스처 원본 보존.
- UV/인덱스/본/재질/이미지 데이터는 변형 없음 (재패킹으로 GLB JSON 인덱스만 재정렬될 수 있음).

## 실행

```bash
python3 -m pip install -r requirements.txt
python3 build_r36kr.py
python3 pose_surface_report.py --output output/POSE_SURFACE_REPORT.json
```

별도 작업 폴더에서는 `--input-dir`로 R36KQ GLB 2종의 위치를 지정합니다. GitHub 체크아웃 상태에서는 형제 폴더 `../r36kq/`의 GLB를 자동 사용합니다. 빌드는 기존 원본 GLB를 수정하지 않고 `output/`에 산출물을 작성합니다.

## 시각 비교

`preview/compare.html`을 로컬 브라우저로 열면 정면/사선 각도에서 R36KQ/R36KR 소프트웨어 렌더를 오버레이할 수 있습니다. 브라우저의 `file://` 로드로 GLB를 가져오지 않으므로 로컬 CORS 오류를 피합니다. 원본 모델의 게임상 색감 검증으로 사용하지 마세요.

## 반증 조건 및 미완료

1. 실제 S2/S3 포즈에서 R36KQ보다 접합 틈이나 메시 관통이 커진다면 R36KR의 사용 이점을 철회합니다.
2. 파일의 텍스처/원본 얼굴/헤어/손/본/트라이앵글이 변경됐다면 회귀 오류로 취급합니다.
3. 법선이나 몸통 가중치 전이로 광원 아래 밝기 띠가 생기면 스킨 가중치 혼합을 재조정합니다.
4. 현재 구조는 **위상학적 weld가 아닙니다**. 완전한 연결로 표시하지 않습니다.
5. 고밀도 해부학 donor의 전면 결합 및 게임 엔진 통합은 미완료입니다.
