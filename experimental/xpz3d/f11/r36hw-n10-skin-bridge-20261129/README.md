# R36HW-N10 — 원본 복부/다리 경계 기반 골반 개방형 피부 시제품

원본 R36HW 유래 **N9 GLB**만 입력으로 사용한다. 기존 고밀도 R36JB 몸체의 전면 교체, 참고 사진 전체 투영, 원본 얼굴·헤어 변경을 수행하지 않는다.

## 실제 코드 변경

- 닫힌 골반 메시 상단 덮개 **16삼각형** 제거
- 기존 반바지 아래쪽에 겹쳐 있던 평면 덮개 **97삼각형** 제거
- 기존 HW `Visible midriff` 하단 10정점 피부 외곽선으로 골반 상단 16정점을 보간해 이동 (상단 최대 **32.70mm**)
- 양쪽 HW 노출 다리의 7정점 테두리와 하단 피부 경계를 근접 조정 (최대 **12mm**)
- 전방 피부 3회 곡면 완화와 국소 주름 함몰 형상 보정
- 원본 피부·눈·얼굴·헤어·63본 유지, 골반의 기존 본 가중치·UV는 계승
- 전체 삼각형 **2,098 → 1,985**, 골반 primitive **362 → 249**. 회수된 113삼각형은 무조건 재추가하지 않는다.

## 확인 상태/한계

GitHub Actions가 생산한 GLB와 보고서에 기하 수치를 기록한다. **중요:** 이 모델은 완성된 탈의 모델이 아니다. 골반 측면과 뒤쪽 일부는 여전히 의복 기원의 메시이며, 피부 경계의 정점 수 차이로 *위치 맞춤*만 수행했지 **실제 용접(weld)되지 않았다**. UV도 전신 재토폴로지는 아니다. 시각적 완성도, 실제 S2 네이티브 PBR 및 63본 동적 스키닝은 미승인.

원본 R36HW 및 N9 GLB는 변경하지 않는다.
