# V15 N19-derived relief panel

V14 shoulder-optimized athletic suit is the immutable base. N19's central geometry (preserved in N20 primitive 3) drives a separate opaque colored fabric relief panel. No nude donor geometry is directly rendered. Added local triangles are allowed beyond 2100 to protect visual quality.

Files: source/build.cjs, output/R36HW_F11_ATHLETIC_SUIT_V15_N19_RELIEF.glb, reports/build.json. Workflow: xpz3d-r36hw-v15-n19-relief.yml.

Visual acceptance and native S2 rendering remain separate tasks.
