# R36HW N5 — 원본 피부 UV 일원화·경계 연결 메시

## 제작 범위
- R36HW 원본에서 유래한 N4 GLB를 그대로 기초로 사용한다. R36JB 몸체를 읽거나 대체하지 않는다.
- 기존 N4 피부 재질(512×512 컬러 및 미세 노멀 텍스처)을, 이전까지 UV가 없던 노출 피부 primitive **230정점**에도 연결한다.
- 원본 재킷 하단에서 실제로 열린 경계를 추적하고, R36HW의 원래 피부 표면에 가장 가까운 기존 피부 정점을 연결하는 **스킨 가중치가 있는 브리지 메시**를 추가한다.
- 재킷 경계에서 위치가 중복되는 에지들은 하나로 취급하며, 접합 메시는 GLB primitive에 추가되어 실시간 스킨 구조가 연결된다.
- 얼굴·헤어 정점/노멀/원본 UV를 변경하지 않는다. 기존 기하 버퍼는 유지하고 새 accessor만 추가한다.

## 실행
저장소 루트에서:

```bash
node experimental/xpz3d/f11/r36hw-n5-skin-seams-20261128/source/build_r36hw_n5.cjs
```

입력은 `r36hw-n4-skin-material-20261128/output/R36HW_N4_SKIN_DETAIL.glb`.
산출물은 `output/R36HW_N5_SEAM_LINK.glb` 및 `reports/R36HW_N5_SEAM_LINK.json`.
일관된 빌드는 GitHub Actions `.github/workflows/xpz3d-r36hw-n5.yml`에서 수행한다.

## 미완료·실패 인정 기준
N5는 의복 전체가 제거된 완전한 탈의 모델이 아니다. 원래 바지·부츠·장갑은 닫힌 형태의 독립 표면이어서 열린 가장자리 연결 작업만으로는 피부로 복원되지 않는다. 재킷 접합 패치도 국소적인 구멍을 줄이는 단계일 뿐, 모든 가려진 피부가 존재한다고 주장하지 않는다.

향후 필수 작업은 의복 기하의 **부위별 국소 재구성**, 텍스처/UV 경계 보정, 목표 사진과 비교 가능한 실제 조명 CLAY 렌더링, 네이티브 S2 골격 애니메이션과 PBR 재질 연동이다. S2의 기존 정적 CMemObject 경로는 UV·노멀맵을 사용하지 못하므로 시각 품질 승인의 근거로 취급하지 않는다.
