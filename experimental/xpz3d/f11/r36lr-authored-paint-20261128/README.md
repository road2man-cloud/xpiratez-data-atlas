# R36LR — HW 방식 설계형 피부 채색 생산기 (2026-11-28)

## 개발 의도

이 버전은 R36LP/LQ의 **기존 픽셀 경계 보정**과 다르다. 사용자의 요구에 따라 HW 의복처럼 **색상과 표면의 방향성 있는 그림을 실제로 생성**하기 위해 `source/paint_layers.cjs`에 신체 구간별 붓질 곡선을 수동 설계하고, `source/build_r36lr.cjs`가 이 곡선을 전신 피부 UV 2048 아틀라스의 각 픽셀에 투영한다.

### 실제 설계 레이어

- 흉부: 양쪽 아래 형태 전이선, 그에 맞닿는 밝은 선, 둥근 볼륨 반사광, 바깥쪽 음영
- 복부: 양측 자연스러운 테이퍼, 중간색 반사광, 중앙 얕은 음영, 하복부 반사광
- 골반: 좌우 음영 곡선, 림 하이라이트, 피부 색조, 허벅지 이행부
- 팔과 다리: 어깨 볼륨, 위팔/아래팔 방향성 반사광, 팔꿈치 및 무릎 전이선, 허벅지·정강이 장축 하이라이트
- 전체: 픽셀마다 모델공간 위치에 종속된 낮은 강도의 피부결과 안료 변화
- 독립 노멀 레이어: 기존 R36LQ 노멀을 교체하지 않고 붓질 높낮이의 미세한 편차를 추가
- ORM 레이어: glTF 거칠기 채널(G)에 부위별 변화, 기존 AO(R)/metallic(B)은 보존

이것은 각 삼각형의 ID를 기준으로 색상을 반복하지 않으며, 3D 공간의 연속곡선을 통해 UV 아틀라스 전역에 회화적 음영을 투영한다. 참고 사진을 실제 깊이 측정이나 정확한 해부학적 스캔으로 취급하지 않는다.

## 보존

- 입력: `r36lq-seam-fairing-20261128/output/balanced/R36LQ_BALANCED_2100_FULL.glb`
- 얼굴/헤어: R36HW 계열 968삼각형 유지
- 몸체: 1,132삼각형, 전신 2,100삼각형 유지
- 기존 63본/스킨 웨이트/UV/전신 메시는 변경하지 않음
- 원본 피부색을 바탕으로 밝고 어두운 붓질을 **국소적으로 추가**하고, 원본 GLB는 덮어쓰지 않음

## 작업물

- `source/paint_layers.cjs`: 영역별 직접 설계한 곡선, 높이, 색상, 거칠기, 미세 안료
- `source/build_r36lr.cjs`: 실제 UV rasterizer + 컬러/노멀/ORM PNG + 완성형 GLB 패킹
- `preview/index.html`: ART / SUBTLE / R36LQ 원본 비교 뷰어, 전신·골반·흉부·얼굴, 0°·35° 포즈
- `.github/workflows/xpz3d-r36lr-production.yml`: Node.js 22, ART/SUBTLE 생산, GLB/PNG 보존, main에 비강제 게시

자동 빌드의 결과 파일은 `output/art/R36LR_ART_2100_FULL.*` 및 `output/subtle/R36LR_SUBTLE_2100_FULL.*`에 생성되도록 구성했다. 이 README 자체는 **바이너리 생산 완료 증빙이 아니다**. 결과 검증은 실제 생성된 `*.report.json`의 해시와 Actions 실행 성공 여부를 우선한다.

## 남은 문제

- 0° / 35° 실제 캡처와 S2 엔진 외관은 별도 시각 비교 필요
- 사용자가 제공한 목표 이미지의 상세 형상을 정확히 복원했다고 주장하지 않는다
- 2,100△ 전신 저폴리 메시에서 생기는 거시적 곡률 부족은 이후 재토폴로지 작업이 필요
- 생성된 피부색을 원본 X-Piratez 스프라이트와 공통 색관리 조건으로 다시 비교해야 한다

**작업 방식:** Python 없이 GitHub Actions의 Node.js 사용. 기존 프로젝트 원본 데이터 덮어쓰기 금지.
