# R36HW N9 — 실제 원본 몸체에 기반한 골반 전방 피부형 곡면

R36HW-N8의 정면 CLAY 이미지에서 여전히 반바지 형태와 다이아몬드형 삼각형 주름이 남아 있어, **기존 의복형 전방 표면의 실제 정점 고도를 다시 구성**한 시제품.

- N8의 2,098삼각형·63본 GLB에서 출발; R36JB 등 별도의 몸체를 가져오지 않음.
- 원본 HW 노출 다리의 두 7정점 테두리 링을 이용해 전방 의복 하단을 실제 피부 표면 쪽으로 연속적으로 연결함.
- 의복에서 유래한 전방 면을 매끄러운 타원형 몸통 곡률로 제한적 리셰이프하며, 국소 좁은 접힘·함몰 구조를 **정점 Y 변위**로만 추가함.
- 골반 primitive의 183정점을 재배치하되, N3/7B의 91개 세분 정점은 인접 원본 표면에 재투영하여 톱니형 플레이트 현상을 완화함.
- 원본 얼굴 644삼각형·머리카락 294삼각형·63본 골격·노멀/색상 등 기존 부위를 가능한 한 유지.
- 외부 사진을 UV로 투영하거나 이미지 전체를 GLB에 붙이지 않음.

## 재현
```bash
node experimental/xpz3d/f11/r36hw-n9-direct-skin-front-20261128/source/build_r36hw_n9.cjs
```

산출물: `output/R36HW_N9_DIRECT_SKIN_FRONT.glb`, `reports/R36HW_N9_DIRECT_SKIN_FRONT.json`.
N9 모델은 2,098삼각형, 골반 정점 183, 앞면 위치 조정 85정점, 하단 다리 연결 위치 조정 66정점, 중심 분할 정점 91개 완화, 최대 정점 이동 33.09mm, 최소 삼각형 면적 1.129×10⁻⁷ m². 이것은 **계산상 GLB 산출 사실**이며 시각 품질 승인이 아님.

## 남은 한계
등·측면과 장갑/부츠 등은 이전 의복형 메시의 원형이 남아 있다. 골반 전방도 정확한 인체 측정치로 복원된 것이 아니라 원본 HW와 입력 이미지의 상대적 곡률을 참고한 근사 표면이다. 원본에서 가려진 피부를 전 부위 복원하지 않았고, 네이티브 S2 UV/노멀/실시간 63본 스키닝은 여전히 미구현이다.

시각적 합격 여부는 동일 조명 CLAY와 실제 UV 사용 PBR/S2에서 별도로 판단한다. CPU 진단 렌더링을 S2 네이티브 캡처라고 칭하지 않는다.
