# R36HW N7B — 직접 몸체 기반 하단 경계 연속화

이 버전은 다른 작업자의 `r36hw-n7-continuous-hem-20261128`과 독립된 분기 실험이다. R36HW N6의 기존 기하를 입력으로 하며 R36JB 고밀도 몸체를 쓰지 않는다.

## 생성된 구조 변화

- 원본 N6: 2,080삼각형 → N7B: **2,098삼각형**. 기준 예산 2,100 이하.
- 원본 GLB `skin` 영역에 정의된 양쪽 다리 상단 정점 고리를 직접 읽고, 골반 하단 삼각형 띠를 그쪽으로 점진적으로 맞춘다.
- 원본 바지 영역의 기존 정점에 3회 인접형 완화와 매우 얕은 전방 곡면 변형을 적용한다.
- 중심부 9개 원래 삼각형을 3개씩 분할하여 순증가 18삼각형. 신규 본 가중치는 인접 원본 정점에서 보간하고 재정규화한다.
- 얼굴 644삼각형·머리카락 294삼각형·63본은 유지한다.

## 자체 피드백에 따른 강제 수정

1차 생산에서 다리 연결 경계를 맞추는 정점 이동이 최대 **72.36mm**까지 커졌다는 문제를 발견했다. 원본 실루엣 보호를 위해 **한 정점당 하단 경계 맞춤 이동은 11.5mm 이하**로 제한한 상태로 생산기를 수정했다. 원본 외형 유지를 희생하면서 경계를 억지로 일치시키는 결과는 성공으로 취급하지 않는다.

## 재현 및 위치

```bash
node experimental/xpz3d/f11/r36hw-n7-hem-continuity-20261129/source/build_r36hw_n7.cjs
```

- `output/R36HW_N7_HEM_CONTINUITY.glb`: 2,098삼각형 실제 GLB
- `reports/R36HW_N7_HEM_CONTINUITY.json`: 삼각형·정점 이동·해시 감사
- `../r36hw-n7b-mesh-render-20261129/output/`: 실제 메시로부터 생성한 정면·사선·측면 × CLAY·SHADED × 전신·국소뷰
- `../r138m-hw-n7b-native-20261129/output/`: 기존 S2의 정적 바인드 포즈 연결용 XPZC 패킷

**완성 한계:** 기존 의복에서 파생된 닫힌 표면과 의복 UV가 남아 있으며, 11.5mm 제한으로 인해 모든 경계가 정확히 용접되는 것은 아니다. 실제 네이티브 S2의 UV·노멀맵 및 63본 애니메이션 적용은 미완료다. CPU 진단 캡처를 네이티브 S2 이미지로 주장하지 않는다. 목표 사진은 텍스처로 삽입하지 않는다.
