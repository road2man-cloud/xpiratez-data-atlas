# R36HW F11 V8 textured athletic outfit

V7-derived opaque athletic garment. Fourteen independent UV charts, 4-pixel gutters, 718 seam-split vertices and tangents, 512x512 procedural RGB normal atlas embedded in the GLB and supplied as PNG. 2,096 triangles and 63 joints preserved. Native S2 shading and visual acceptance remain unverified.
