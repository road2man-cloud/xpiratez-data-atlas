# R36MI — 신규 폴리곤 정점을 구조 곡선에 직접 정렬 (2026-11-28)

## 문제와 실제 해결 작업

R36MH는 몸체의 평탄한 영역에서 삼각형을 회수하고 중심부에 새로운 삼각형 24개(DENSE)를 공급했지만, 새 중심 정점은 기존 삼각형의 단순 무게중심에서 출발했다. 따라서 추가된 폴리곤이 **사용자가 제시한 윤곽의 굴곡을 제대로 따라가지 않는 문제**가 남아 있었다.

이번 R36MI에서는 새 정점을 식별한 다음 **기존 물리 정점이 아닌 새로 공급된 정점만** 한정적으로 X/Y/Z 방향 이동시킨다. 곡선은 기존 `r36mc-landmark-sculpt-20261128/source/landmark_hypothesis.json`에서 읽으며, 사진 한 장으로 실제 깊이가 측정된 것처럼 취급하지 않는다.

## 실제 제작한 소스

- `source/build_r36mi.cjs`: R36MG와 R36MH의 물리 정점 위치 그룹을 비교하여 이전에 없던 신규 중심 정점을 식별하고, 8개 구조 윤곽선 중 가까운 선분에 맞춰 이동. 각 면의 면적비·뒤집힘·노멀 방향을 제한하고 UV 분할 정점들을 함께 이동. 해당 삼각형의 노멀/탄젠트와 2048 노멀맵도 실제 3D 프레임에 맞춰 이송.
- `.github/workflows/xpz3d-r36mi-contour-control.yml`: Node.js 22에서 ART/SUBTLE × DENSE/GUARDED 후보를 각 1회 생산하고, 전체 전신 GLB 4개와 CLAY 4개, PNG, JSON 보고서를 GitHub `main`에 게시.
- `preview/index.html`: 정면 −Y·수직 +Z 카메라 및 동일 조명에서 R36MH와 R36MI의 단색 CLAY 또는 텍스처 전신 비교.

## 변하지 않는 구조

- 전체 2,100삼각형 = 몸체 1,132 + 머리·헤어 968.
- 골격 63본, 기존 본 인덱스·스킨 웨이트, UV, 컬러 및 ORM 이미지 유지.
- R36MH에서 추가된 정점의 위치와 연결된 면의 법선·탄젠트·노멀 이미지 텍스처만 보정.
