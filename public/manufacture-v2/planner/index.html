실행 가능성 판정기가 아닙니다. 사용자가 세이브를 선택하면 기지 저장 물자와 discovered 연구 목록만 브라우저에서 확인합니다. 시설·이벤트·실제 구매 가능성과 연구 조건의 논리식은 확인하지 않습니다. 제조비 및 시간은 규칙에 직접 선언된 숫자만 합산하며 미확인 단가나 엔진 기본값은 채우지 않습니다.

위 가정은 규칙에 산출 수량이 없을 때만 사용합니다. 기본값은 꺼짐입니다.

제조식

선택 기지의 시설·제조 주문

원료별 제조 경로 선택

복수 제조식이 있는 재료는 기본적으로 직접 조달로 남깁니다. 아래에서 원하는 제조식을 선택하면 트리가 재계산됩니다. 단일 제조식도 직접 조달로 변경할 수 있습니다.

생산 경로 비교

표는 동일한 시작 재고를 사용한 독립 시나리오입니다. 일부 외부 조달 가격이 있더라도 실제 최저비용이나 게임 내 제조 가능성은 확정하지 않습니다.

기지 제조 주문 + 신규 생산 수급 시뮬레이션

실제 잔여 제조량 계산이 아닙니다. 세이브에 이미 등록된 주문에서 추가로 한 회씩 생산한다고 가정하고, 신규 제조식도 함께 현재 재고에서 순차 계산합니다. 저장된 amount·spent·assigned는 기존 진행 정보로만 표시하며 과거에 쓴 재료를 다시 차감하지 않습니다.

가상 실행 순서제조비 / 명시 작업량기초 재고 사용 / 이전 계획 산출물 사용외부 조달미확인 조건

추가 조달 체크리스트 · 첫 부족 주문 기준

어떤 주문에서 재료가 처음 부족해지는지, 어느 후속 주문에서도 필요한지 표시합니다. 구매 가능성이나 실제 게임의 보유 재고 변경을 뜻하지 않습니다.

가상 재료 확보 후 제조 계획 비교

아래 수량은 새로 확보한다고 가정하는 수량입니다. 게임이나 기존 보유 재고를 변경하지 않으며, 실제 구매·생산 가능성은 확인하지 않습니다.

재료별 부족량 변화

주문별 재료 부족·기타 제약

주문별 실행 장애 요인 · 증거 기준

재료 충족은 이 가상 시나리오 내부에서만 의미가 있습니다. 기지 시설과 세이브 연구 목록에 없는 조건은 별도로 표시하며, 어떤 경우에도 실제 제조 가능 판정으로 취급하지 않습니다.

중복 통합 우선 조치 목록

공통 재료·시설 기능·연구 확인 항목을 여러 주문에 걸쳐 묶었습니다. 순위는 처음 영향을 받는 주문 기준이며, 게임 내 실행 가능성을 확정하지 않습니다.

재고 출처: 기초 입력과 가상 추가 수량 분리

기초 입력에는 세이브를 불러온 뒤 수동으로 수정한 수량도 포함될 수 있습니다. 게임의 실제 획득·소비 기록을 추정하지 않고, 두 출처가 섞인 재고의 소비량은 가능한 범위로만 보여줍니다.

모든 선택 주문을 합친 재료 수급표

생산 순서별 외부 조달 부족량 차이

같은 재고를 독립적으로 사용해 신규 제조식 먼저와 기존 선택 주문 다음을 비교합니다. 순서 변경으로 줄어드는 미확보 재료만 표시하며, 실제 게임의 완료 시각이나 최적 운영을 확정하지 않습니다.

각 주문의 입력 재료는 공통 창고에서 순서대로 소비됩니다. 앞선 가상 제조로 생긴 확정적 산출물만 다음 주문에 넘깁니다. 외부 조달은 자동 구매하지 않습니다. 명시된 작업량의 합은 실제 완료까지 걸리는 시간이 아닙니다.

단계별 제조·재료 트리

각 제조 단계 비용은 명시된 제조비 × 제조 횟수입니다. 기초 재고와 앞선 제조에서 남은 산출물은 후속 분기에 재사용하며, 계산 순서에 따라 경로가 달라질 수 있습니다.

통합 재료·재고 수급표

모든 제조 단계에서 같은 재료 ID를 합산합니다. 입력한 보유 재고를 먼저 사용하고, 이미 만든 잉여 산출물·동시 생산물을 재사용합니다. 화면에는 최대 200종, CSV에는 전체 계산 항목이 포함됩니다.

외부 조달·미해결 재료

제조식으로 확장하지 않은 재료입니다. 구매가가 있어도 실제 판매 중이라는 의미는 아닙니다. CSV에는 현재 계산의 전체 외부 조달 목록이 포함됩니다.

부족 재료의 확보 가정으로 새 제조 계획을 미리 비교하거나, 재고 입력으로 수량을 옮길 수 있습니다. 가상 계산은 원래 입력·세이브를 변경하지 않습니다.

선택 재료 일괄 확보 가정 결과

선택한 부족분을 모두 추가 보유한 독립 시나리오입니다. 원래 재고·세이브·제조 계획은 변경하지 않습니다.

재료 부족 해소만으로 실제 생산 가능 여부가 결정되지는 않습니다. 연구·시설·이벤트와 시장 구매 가능성은 별도 확인이 필요합니다.

단일 재료 확보 가정 결과

시뮬레이션은 현재 제조식·경로·재고 입력에만 적용됩니다. 게임 내 확보, 시장 구매 가능 여부, 시설·연구 충족을 보장하지 않습니다.

관련 연구 조건

규칙에 직접 명시된 연구 ID와 선행 ID를 추적합니다. 유효한 세이브를 선택했다면 discovered 목록에 있는지 표시합니다. 조건의 AND/OR, 이벤트·시설별 잠금은 해석하지 않습니다.

제약·불확실성

출처: 2.1 설치본 SHA-256 명세. 구형 1.1 DB·별도 모드의 규칙은 사용하지 않습니다. 사용자가 선택한 2.1 세이브의 기지 저장량 및 discovered ID만 참고하며 세이브를 서버로 전송하지 않습니다.
