원본 연구 관계 불러오는 중…

게임의 YAML 세이브에서 discovered, researchRuleStatus, researchDiary의 연구 기록만 브라우저 안에서 분석합니다. 파일은 서버로 전송하거나 저장하지 않습니다.

공백·쉼표·줄바꿈 구분. 직접 입력하거나 {"completed":["STR_…"]} JSON을 붙여넣을 수 있습니다. 수동 적용은 가져온 .sav의 영구 배제 상태를 초기화합니다. 정확한 상태 확인에는 위의 세이브 파일을 이용하세요.

판정 기준: 직접 봉쇄는 원본 disables의 방향대로 계산하고, 완료 연구 플래그도 제거합니다. OXCE의 unlocks는 dependencies를 우회하지만 requires까지 우회하지는 않습니다. 원본 getOneFree의 중복 연구 ID는 추첨 가중치로 보존합니다. 무료 연구 지급은 실제 무작위 추첨·조건부 보상·자동 0비용 연구·실물·시설·이벤트·시기를 충족했다고 가정하지 않습니다. 세이브의 연구 가능 여부를 확정하는 시스템이 아니라 완료를 가정한 분기 위험 분석입니다.

해석 기준

  • ‘자연 접근’은 해당 선장/분기가 필요한 성향 태그를 직접 열어 주는 경우입니다. 실제 연구에는 별도 기술·시설 선행이 더 있을 수 있습니다.
  • ‘후기’는 Codex Awakened, 혼돈의 성자, 추가 성격검사 등으로 뒤늦게 가능해지는 경우를 뜻합니다.
  • 월 기대수익은 직접 현금과 현재 난이도에서 즉시 판매 가능한 지급품만 돈으로 환산한 값입니다. 병사·연구 해금·임무·점수는 0원 취급하므로 전략 가치를 과소평가합니다.
  • 방사탑/Flak은 지나가는 UFO를 자동사격하지 않습니다. UFO가 기지를 실제 공격할 때 Base Defense 단계에서 발사합니다.
