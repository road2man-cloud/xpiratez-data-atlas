출생처별 비교

잠정값의 계산 범위와 갱신 원칙

각 출생처는 독립된 병사입니다. 현재 수치 시나리오는 원본 출생 최솟값에서 시작하며, 선택한 동일 병사의 연구·획득·훈련 순서를 재생합니다. 실제 전투 성장, 체육관 성장, 신규 훈장, 승진을 자동 가산하지 않습니다.

등록한 잠정값은 이 제한된 탐색 범위의 최고 발견값입니다. 재료·표본·시설·자금·이벤트와 난수 가정을 상세에 기록하며, 연구 공급 경로가 완결되지 않은 출생처에는 최종 수치를 임의로 넣지 않습니다.

더 높은 후보를 찾더라도 원본 버전·출생 이력·연구 순서·배제를 다시 검사한 뒤 갱신합니다. 기존 후보는 비교용으로 남깁니다. 목표 A인 영구 보너스 합계와 목표 B인 최종 능력치 합계는 따로 비교합니다.

확정 최종 최대치는 실행 가능성과 더 높은 경로가 없다는 전역 최적성이 모두 증명된 경우에만 사용합니다. 현재 인증은 0건입니다.

연구 관계 · 조건과 영향
