현재 세이브를 불러오면 이 83개 경로에 대해 완료 연구·직접 폐쇄·이벤트 우회 가능성을 함께 대조합니다. 명목 선행망이 막힌 경우라도 실제 이벤트 획득을 전부 검증하기 전에는 영구 제외하지 않습니다.

판정 기준·남은 불확실성

실제 2.1 기본 바디 생성값 → 획득형 능력치 오버라이드(0은 기존값 유지) → 자동 SoldierBonus 1회 적용. 변신은 순서별로 현재 병종, 필수·금지 이력, 연구·시설·아이템·훈장·능력치를 검사합니다. 방어구는 한 벌만 착용 가능하고, 미획득 장비의 보너스를 자동 합산하지 않습니다. 확정 불가능과 미충족 조건, 단순히 미래에 얻을 수 있는 후보를 구분합니다.

변신 경로 상호배제 검증 선택된 대원의 실제 이력과 변신 실행 순서로 재판정합니다. 완성되지 않은 조건은 가능한 것으로 확정하지 않으며, ‘현재 즉시 실행’은 세이브의 기지 자원까지 자동 대조합니다.
미래 성장 단계 (가정) 성장 단계와 변신을 원하는 순서대로 배치합니다. 이 단계는 실제 실행 내역이 아닌 장기 성장 상한의 가정이며, 해당 성장량을 획득했다는 증거가 아닙니다.
변신 순서별 능력치 안전 범위 (12종)

초기 생성값·변신의 비례 변화·무작위 변화·성장 상한을 OXCE 산식으로 계산한 보수적 포함 범위입니다. 범위 내 모든 값이 동시에 가능한 것은 아니며, 미래 전투 경험치 성장, 장비 획득과 미검증 이벤트는 포함되지 않습니다.
