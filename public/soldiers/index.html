병종 DB

“병종”을 29개의 내부 바디 규칙으로 축약하지 않습니다. 실제 획득 루트마다 초기 고정 스탯·자동 특성이 다르면 별도 생성형으로 분리하고, 특성 능력치까지 합산한 실전 생성 스펙으로 비교합니다.

최종조합 출처
최종 기본형 (변형 후 포함)
실제 획득형 계산 기본 Soldier 랜덤치 → 획득 루트의 spawnedSoldier.currentStats 덮어쓰기 → 생성 시 transformationBonuses 능력치 합산 → OXCE 최소치 보정. 표의 각 능력치는 현재 실효값 / 성장 하드캡으로 표시합니다. 하드캡은 최종 병종의 statCaps에 보유 특성(SoldierBonus)의 능력치 보너스를 합산한 일반 성장 상한입니다. 훈련캡(trainingStatCaps)은 별도 값이며, 특수 생성·변환으로 일반 성장 상한을 넘는 능력치는 절대 최대치로 잘못 해석하지 않도록 붉게 구별합니다. 방어구 보너스는 포함하지 않습니다. 최종 강화 조합은 병종·변신 순서만 만족하는 이론적 상한 후보입니다. 선장·Codex·여왕 분기, 연구 획득 이벤트 및 희귀 실물 재료가 모두 충족됐다는 뜻은 아닙니다. 원본에서 확실히 확인되는 내부 전용·선장 전용 동시 선택·야만 여왕/Codex 충돌은 별도 감지하여 기본 표에서 제외합니다. 남아 있는 조합도 캠페인 실행 가능이 확정된 것은 아닙니다. 실제 병사 훈련 경로는 병사훈련 DB에서 검토하세요.
