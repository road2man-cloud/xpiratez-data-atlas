병종 DB

병종의 기본 규칙·획득형·강화 조합과 최신 능력치 검증을 하나의 병종 DB에서 탐색합니다. 같은 병종도 출생처·초기 특성·성장 이력이 다르면 별개의 대원입니다. 데이터 버전은 구분하며 서로 혼합하지 않습니다.

현재 표: X-Piratez v.o1.1.1. 2.1 능력치·연구 분석은 위 병종 DB 보기에서 선택할 수 있습니다. 2.1에서 실제 연구·성장·훈장·변신 순서와 최적성이 확인되지 않은 수치는 확정값으로 취급하지 않습니다.

최종조합 출처
최종 기본형 (변형 후 포함)
고급 계산 기준 · 강화 분기 설명 펼치기 기본 Soldier 랜덤치 → 획득 루트의 spawnedSoldier.currentStats 덮어쓰기 → 생성 시 transformationBonuses 능력치 합산 → OXCE 최소치 보정. 표의 각 능력치는 현재 실효값 / 성장 하드캡으로 표시합니다. 하드캡은 최종 병종의 statCaps에 해당 획득형의 시작 특성과 선택한 강화 경로에서 실제 부여되는 특성만 합산한 일반 성장 상한입니다. 기본 병종이 같다는 이유로 다른 영입형의 특성을 공유하지 않습니다. 예를 들어 일반 영애는 독수리눈이 없고 첩보원 영애는 영입 시에만 독수리눈을 받습니다. 훈련캡(trainingStatCaps)은 별도 값이며, 특수 생성·변환으로 일반 성장 상한을 넘는 능력치는 절대 최대치로 잘못 해석하지 않도록 붉게 구별합니다. 방어구 보너스는 포함하지 않습니다. 최종 강화 조합은 병종·변신 순서만 만족하는 이론적 상한 후보입니다. 선장·Codex·여왕 분기, 연구 획득 이벤트 및 희귀 실물 재료가 모두 충족됐다는 뜻은 아닙니다. 원본에서 확인되는 내부 전용·선장 고유 동시 선택·야만 여왕/Codex·Diverging Paths 분기 상호배제는 기본 표에서 제외합니다. 갈림길을 직접 선택하면 그 분기에서 얻을 수 없는 특성 강화도 제외합니다. 남아 있는 조합 역시 이벤트/선장 진행/실물 조건 때문에 실행 가능이 확정된 것은 아닙니다. 연속 병종 전환은 원본의 이력·병종 배제를 매 단계 적용하며, 사망 대원에게만 가능한 전환은 사망·부활 과정을 임의로 가정해 다른 전환과 자동 연결하지 않습니다. 실제 순서·훈련 조건은 병사훈련 DB에서 검토하세요.
