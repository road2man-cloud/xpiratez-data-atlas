# X-Piratez 3D — Stage 06: Native source integration seam

**2026-11-01: 19/19 Linux unit/integration tests PASS**, both in the working tree and after a clean ZIP extraction. The standalone C++14 parser builds with `-Wall -Wextra -Werror -pedantic` and consumes three synthetic test frames. The GitHub source files under this directory were verified **byte-identical** to the corresponding tested local source files by matching Git blob SHA-1.

**This is a source-level integration seam, not a running Silent Storm game, and not original OXCE combat parity.** The output image is explicitly **synthetic**. No copyrighted original game assets are redistributed.

## Design

OXCE / X-Piratez remains the sole authority for Geoscape, research, base economy, inventory, TU, combat, RNG, awards, mission outcomes and saved campaign state. Silent Storm Reconstruction is intended only for a lawful 3D map/scene/camera/art runtime. The adapter is **read-only**: never apply visual updates to an OXCE campaign save.

The existing original-engine native runner is in [`tools/headless-simulator`](../../../tools/headless-simulator) (merged PR #39). The deterministic full-checkpoint work is in PR #48 (not merged at this inspection). Do not re-enable an approximate surrogate engine.

The core files committed **in this directory** are:

- `ss/XPZVisualFeed.h`, `ss/XPZVisualFeed.cpp`: C++14 visual-only snapshot receiver; an optional `XPZ3D_VISUAL_FEED` Win32 environment variable enables once-per-frame polling. It **stores** positions/stats in memory and logs changes but **does not spawn Silent Storm world objects**.
- `ss/visual_feed_test.cpp`: Linux/portable executable to check feed ingestion.
- `tools/export_visual_feed.py`: OXCE `native_ready`, `checkpoint`, optional requested-fire message → transactional visual feed. Optional SHA256 of genuine full checkpoint files.
- `tools/make_optin_patches.py`: patches **copies** of the OXCE ReplayDriver source and Silent Storm Reconstruction `Game/Main.cpp`/`CMakeLists.txt`; refuses ambiguous anchors. Never overwrites the original game installation. This is a preliminary research-only overlay, not authorization for redistribution or code mixing.
- `tests/test_stage06.py`: 19 source/trace/negative validation checks.

## Reproduce on Linux

From **this directory**:

```sh
python3 -m unittest discover -s tests -v
c++ -std=c++14 -Wall -Wextra -Werror -pedantic \
  ss/XPZVisualFeed.cpp ss/visual_feed_test.cpp -o /tmp/xpz-visual-feed-test
```

An example valid `XPZ3D2` feed is generated by the exporter from a trace: `python3 tools/export_visual_feed.py --trace /path/to/native-events.jsonl --out /tmp/atomic-visual.feed --report /tmp/visual-report.json`. To verify actual serialized native checkpoint bytes, add `--checkpoint-dir /path/to/native/save-directory`. A `native_ready` JSON field is **not** proof of actual native binary identity.

Patch generation (local research worktrees only, independently authorized):

```sh
python3 tools/make_optin_patches.py \
  --silent-storm-checkout /path/to/Silent-Storm-Reconstruction \
  --oxce-adapter-dir /path/to/xpiratez-data-atlas/tools/headless-simulator/native \
  --overlay-output /path/to/NEW-empty-overlay-directory
```

The overlays are generated, **not compiled or executed** in the actual engines. Source anchors in the actual GitHub files were individually verified at the time of writing:

- [Silent Storm Reconstruction `Game/Main.cpp`](https://github.com/met-nikita/Silent-Storm-Reconstruction/blob/develop/Game/Main.cpp)
- [Silent Storm Reconstruction `CMakeLists.txt`](https://github.com/met-nikita/Silent-Storm-Reconstruction/blob/develop/CMakeLists.txt)
- [OXCE native `ReplayDriver.h`](../../../tools/headless-simulator/native/ReplayDriver.h)

## Critical unresolved issues

1. Actual original OXCE shot **impact point/voxel** is **not** available from this output. The recorded target is only the **requested aim**; it must not be displayed as verified trajectory/hit.
2. No live Silent Storm Win32 build, game assets, in-world units, animation, terrain destructibility or engine-linked battle executed in the GPT Linux proof.
3. The Visual Feed receives **original OXCE tiles**, not yet calibrated Silent Storm world coordinates.
4. The stream has consistency hashes, not a verified native-runner signature or authenticated provenance.
5. Nival's [noncommercial revocable license](https://github.com/nival/Silent-Storm/blob/main/LICENSE.md) requires rights analysis before combining with GPL OXCE or shipping a combined package. Separate processes do **not automatically** resolve copyright questions.
