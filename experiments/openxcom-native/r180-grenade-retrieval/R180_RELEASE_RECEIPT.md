## 사용자가 받는 개선

기존 R179는 장전(PRIME) + 투척(THROW)만 표시해, 배낭·허리 장비칸에 있는 수류탄을 손에 꺼내기 위한 TU가 총합에서 누락됐습니다. R180에서는 전투 중(`_tu == true`) 수류탄에 마우스를 올리면:

- 손에 이미 들고 있으면 꺼내기 TU = 0
- 장비칸에 있으면 실제 `BattleItem::getMoveToCost()`를 사용하여 오른손·왼손까지의 **더 싼 이동 TU**를 합계에 포함
- 장전된 수류탄은 `getFuseTimer() >= 0`이면 재장전 비용을 제외
- 필요한 총 TU = 꺼내기 + (미장전이면 장전 TU) + 투척 TU
- 현재 남은 TU보다 총 소모 TU가 많으면 `!` 표시
- 66×24 픽셀 영역에 맞춰 한국어 → 간략형 → ASCII → 합계 전용 표시로 축소
- 전투 준비 인벤토리(`_tu == false`)에서는 의미 없는 '현재 TU 부족' 표시를 하지 않음

**주의:** 실제 손이 모두 차 있는 경우 기존 손 장비를 치우는 추가 TU나 사전 이동·경로·특수 행동 제약은 합계에 포함하지 않습니다. 수치는 수류탄을 손에 들기 위한 *최저* 비용 기반의 전투 TU 추산입니다. 수류탄이 지상 슬롯에 놓인 경우에도 규칙의 손 슬롯 이동 비용을 적용합니다.
