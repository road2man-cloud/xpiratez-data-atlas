# X-Piratez v.o2 제조 계산기 — 공통 재료·조건 검토 작업 통합

**기준:** 2026-11-19  
**기반 커밋:** `d2af94b`  
**브랜치:** `feat/manufacture-shared-review-queue-20261119`

## 실제 추가 기능

현재 확장된 제조 작업표의 **실제 선행 작업 간선**만 따라가서, 하나의 재료·연구·시설·규칙 검토 항목이 여러 제조식에서 참조되는 상황을 집계한다. 같은 항목을 각 제조식마다 복사하지 않고 **한 개의 검토 작업**으로 표시한다.

- 복수 종류의 제조식에 걸치는 **공통 작업**
- 같은 제조식이 여러 번 등장해 걸치는 **반복 제조 작업**
- **단일 제조식** 전용 작업
- 현재 제조식 선행 그래프에는 연결되지 않지만 **독립적으로 확인해야 하는 작업**

사용자는 이 분류로 필터링하고 재료·조건 ID, 이름, 관련 제조식 ID를 검색할 수 있다. 기존 통합 작업표에서 검토 표시를 변경하면 공통 작업 목록의 미검토/검토 집계도 함께 갱신된다. 관련 제조식 작업과 원래 재료·조건 작업으로 이동할 때는 해당 **행을 화면 중앙으로 스크롤**한다.

**CSV 저장:** 제조식별 영향 종류 수, 제조식 등장 횟수, 영향을 받는 제조식 ID·작업 ID, 현재 검토 표시, 가상 참고 수량, 현재 상태 근거, 확인 행동을 **전체 목록**으로 내보낸다. 화면은 100개까지만 표시하지만 CSV는 자르지 않는다.

## 구현

- `public/manufacture-v2/planner/route-shared-review-queue.mjs` — 검토 작업 선행 DAG의 역방향 전파, 중복 방지, 작업 상태 투영 및 전체 CSV
- `public/manufacture-v2/planner/planner-ui.mjs` — 작업표 메모 상태와 연결, 검색·필터·상세 이동, 작업표 선택 행 중앙 스크롤
- `public/manufacture-v2/planner/index.html`, `planner.css` — UI와 스타일
- `tools/test-v2-route-shared-review-queue.mjs` — 공유·반복·단일·연관 없음, 다이아몬드 의존 그래프의 중복 제거, 상태 변경·재계산 영향 분리·교차 버전 보호 테스트
- `package.json` — 제조 계산기 통합 자동 테스트 명령에 새 테스트 등록

## 기술 원칙

- 모든 데이터는 X-Piratez **v.o2** 현재 제조 작업표에만 한정한다. 1.1 DB와 혼합하지 않는다.
- 같은 제조식의 여러 등장 노드는 **발생 횟수**로 집계하고, 서로 다른 제조식 ID 종류 수는 별도로 집계한다.
- 하위 제조식→상위 제조식의 실제 선행 의존을 전파하지만 같은 제조식 노드를 여러 번 만나도 중복 계산하지 않는다.
- 작업 종류와 이름이 같더라도 고유 작업 ID가 다르면 억지로 하나의 완료 기록으로 병합하지 않는다.
- 현재 제조식과 연결되지 않은 검토 항목을 임의로 연결하지 않는다.
- 자동으로 체크하거나 실제 재료 확보·연구 해금·시설 완공을 선언하지 않는다. **검토 표시는 사용자 로컬 메모**다.
- 기존 세이브, OXCE 실행파일, 규칙 및 한글 번역은 변경하지 않는다.

## 검증과 배포 구분

변경된 Node 모듈의 단위 테스트를 통과했으며, 전체 제조 계산기 테스트는 `npm run check:manufacture:planner:v2`로 확인한다. 이 검사는 실게임 제조 실행, 실제 공개 사이트 배포 또는 브라우저의 모든 사용자 동작을 증명하지 않는다. `main` 병합은 별도 단계다.
