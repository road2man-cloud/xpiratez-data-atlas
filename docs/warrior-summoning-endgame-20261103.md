# 용사 소환: 존 추적자 vs 오우거 스파이 (조건부 12능력치 성장 비교)

기준: X-Piratez 2.1 v.o2 / OXCE 8.7.1. 입력 출처는
`soldiers-modern-index.json`, `soldier-origin-candidates.json`,
`soldier-source-catalog.json`입니다.

**중요:** 아래 값은 *전역 최종 최대치*가 아닙니다. 소환 출생처에서 **최저 생성 능력치**로 시작해,
기존 병종 DB에 등록된 완결 연구 재생 경로를 통과한 뒤, 그 병종에서 체력훈련과 전투 경험치로
각 능력치의 낙관적 성장상한에 도달한다고 가정한 값입니다. 실제 전투·훈련 경험치, RNG,
훈장, 연구 경로의 다른 훈련 결합, 변신 후 생존 및 최적성은 증명하지 않았습니다.

| 능력치 | 존 추적자 | 오우거 스파이 | 오우거−존 |
|---|---:|---:|---:|
| 시간단위 | 91 | 96 | +5 |
| 기력 | 131 | 171 | +40 |
| 체력 | 95 | 161 | +66 |
| 용기 | 119 | 119 | 0 |
| 반응 | 90 | 75 | -15 |
| 사격 | 125 | 130 | +5 |
| 투척 | 100 | 100 | 0 |
| 근접 | 110 | 110 | 0 |
| 힘 | 61 | 121 | +60 |
| 정신력 | 49 | 93 | +44 |
| 초능력 기술 | 70 | 30 | -40 |
| 활력 | 196 | 145 | -51 |
| **합계** | **1,237** | **1,351** | **+114** |

두 출생처에서 위 수치를 만든 기존 연구 재생 후보는 **선장의 11 (STR_CAPTAINS_11)** 이력입니다.
훈련 이전의 다른 출생 RNG, 다중 훈련 순서 및 훈련 전후의 전투 성장 순서를 최적화한
결과는 아닙니다. 다른 조건의 후보는 비교 JSON에 별도로 유지합니다.

결과 JSON: `public/data/soldier-summon-endgame-compare.json`.
소스 기반 생성: `node tools/build-soldier-summon-endgame-compare.mjs` (stdout).
엄격한 회귀 검사: `node tools/check-soldier-summon-endgame-compare.mjs`.

연구 경로가 실제로 재생되었다는 사실과 미래 모든 성장상한을 동시에 달성할 수 있다는
사실은 다릅니다. `finalStats`, `finalSum`은 계속 null이며 최종 최대 인증은 0건입니다.
