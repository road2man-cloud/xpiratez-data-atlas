# X-Piratez v.o2 제조 검토 기록함 — 누적 보존 기능

개발 기준: 2026-11-19. 기반 커밋: `a9a0b67`. 본 기능은 X-Piratez v.o2 제조 계획 *검토 기록*만 다룹니다. 게임 세이브·재고·제조 명령·규칙 파일을 변경하지 않습니다.

## 주요 개선

기존 제조 계산기는 재계산 직후 제외된 이전 검토 메모를 그 직전 비교 화면에서만 볼 수 있었습니다. 두 번 이상 변경하면 오래된 메모와 제외 근거가 목록에서 사라질 수 있었습니다.

- 같은 제조 목표의 재계산마다 변경 **차수**를 기록합니다. 해당 차수의 이전·현재 작업 수, 동일 대응 수, 제외된 기록 수, 바뀐/새로운/모호한 작업 수, 자동 보존된 검토 표시와 메모 수를 추적합니다.
- **제외된 과거 검토 기록**은 변경 차수별로 누적합니다. 이전 작업 ID·재료/제조식 ID·이전 수량·검토 표시·메모·제외 사유·관련 제조식 ID를 보관합니다.
- 누적 메모 검색, 메모만 보기, 검토 표시만 보기, 같은 ID를 가진 **현재** 작업표 항목으로 바로 이동하는 기능을 추가했습니다. 이동은 ID 참조일 뿐 의미가 완전히 동일하다는 증거가 아닙니다.
- **누적 기록함 JSON**, **누적 메모 CSV**, **재계산 차수 요약 CSV**를 따로 저장합니다. JSON은 이전 기록 재가져오기에 사용합니다.
- JSON 가져오기는 현재 계획과 제조 목표 ID가 같은 기록만 받아들이며, 이미 들어온 이벤트는 중복 추가하지 않습니다. 같은 이벤트 ID의 내용이 충돌하면 기존 기록을 변경하지 않고 거부합니다.
- 현재 작업표의 검토 표시/메모와 **누적 보관 기록**은 분리합니다. 변경되거나 모호한 작업의 오래된 메모는 절대로 자동 재적용하지 않습니다.
- 신규 작업대에서 기존 JSON을 직접 다시 가져올 수 있도록, 누적 기록함이 비어 있어도 가져오기 UI를 표시합니다.

## 브라우저 사용 순서

1. 제조 경로 작업대에서 제조·조달 계산과 통합 작업표 갱신을 수행합니다.
2. 작업표에 검토 표시/메모를 작성하고, 제조 경로 또는 재료 가상 확보 수량을 수정합니다.
3. `후속 부족 재료 계산 및 통합 작업표 갱신`을 눌러 새 작업표를 계산합니다.
4. 안전하게 동일한 작업의 기록은 복원됩니다. 자동 제외된 메모는 위 누적 기록함에 추가됩니다.
5. **누적 기록함 JSON 저장**으로 작업대 종료 전 백업합니다. 다음 세션에서는 동일한 제조 목표를 열고 **기존 기록함 JSON 병합**을 사용합니다.

## 범위 및 주의

- 보관 메모는 현재 게임의 실제 제조 가능성, 구매 가능성, 연구 해금, 시설 또는 재고 확보의 증거가 아닙니다.
- 브라우저 로컬 메모리만 사용합니다. 페이지를 닫거나 새 작업대를 열면 기록이 보존되지 않을 수 있으므로 반드시 JSON을 저장해야 합니다.
- 한 기록함의 최대 변경 이벤트 수는 1,024개, 제외 항목 수는 12,000개입니다. 초과할 경우 기존 기록을 조용히 삭제하지 않고 오류로 처리합니다.
- 각 이벤트에 부여된 식별자를 통해 같은 기록의 중복 가져오기를 방지합니다. 상충하는 동일 ID는 자동 병합하지 않습니다.
- 세이브, 원본 규칙, 한글 번역, OXCE 실행파일, 다른 작업자의 브랜치를 변경하지 않습니다.
- 브라우저 및 실제 게임 실행 검증은 별도 작업이며, 모듈 자동 테스트 통과를 실제 게임 통합으로 표시하지 않습니다.
