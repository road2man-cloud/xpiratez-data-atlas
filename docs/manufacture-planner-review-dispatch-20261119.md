# X-Piratez v.o2 — 제조 공통 검토의 우선 실행 작업표

**기준:** 2026-11-19  
**기반:** `5cc13ba` (공통 검토·조달 원장·조건 근거 연동)  
**개발 브랜치:** `feat/manufacture-review-dispatch-20261119`

## 실제 새 기능

제조 경로 작업대의 `공통 재료·연구·시설 검토 작업` 안에 **다음 검토 작업 추천** 패널을 추가했다. 사용자의 저장된 검토·메모, 같은 v.o2 목표의 가상 조달 원장과 최종 체크리스트를 함께 사용한다.

### 기본 검토 순서
1. 가상 계산 후 남은 부족 재료
2. 시설 기능과 완공 근거
3. 연구·해금 조건 근거
4. 규칙·기타 조건
5. 가상 확보를 실제로 실행할 수 있는 조달 경로
6. 원장에 확보 수량이 명시되지 않은 재료의 근거
7. 조건에 대한 체크리스트 근거 미기재
8. 현 제조식 선행 그래프와 직접 연결되지 않은 독립 확인
9. 이미 사용자가 검토 표시한 작업

같은 분류 안에서는 관련 제조식 종류 수, 관련 제조식 발생 횟수, 가상 부족 수량, ID 순으로 정렬한다. 이는 사용자가 확인할 일을 **추천하는 정렬 규칙**이지, 게임 내 실제 제조 난도나 제조 가능성의 판정이 아니다.

### 화면 기능
- **현재 미검토 총량**, **원장상 부족 합계(검토 여부 무관)**, **그중 미검토 부족 항목**을 분리 표시한다.
- 선택한 분류의 **다음 미검토 작업으로 이동** 버튼을 누르면 기존 통합 작업표의 해당 행으로 바로 이동한다. 자동 검토 완료 처리나 실제 게임 동작은 수행하지 않는다.
- 각 항목에 추천 확인 작업, 관련 제조식 ID, 가상 부족량과 가상 확보량, 해당 조건 상태, 기존 사용자 메모를 표시한다.
- 80개까지 화면에 보여 주고, **전체 CSV**에는 검토 표시된 항목까지 전부 포함한다.
- 사용자 메모·원본 이름·근거 문자열이 스프레드시트 수식으로 평가되는 위험을 피하기 위해 CSV의 위험 접두사를 중화한다.

### 집계 안전성
검토 체크는 게임 내 재료 확보 상태와 무관하다. 예를 들어 **가상 부족 7개**인 재료에 사용자가 검토 표시를 해도, 원장상 가상 부족 총합은 **그대로 7개를 포함**하고, 미검토 부족 합계에서만 제외한다. 부족 재료가 제조식과 연결되지 않았더라도 원장에 명시되었다면 가상 부족 합계에서 누락하지 않는다.

근거가 불명확한 항목은 임의로 부족 0개, 구매 가능, 시설·연구 충족으로 바꾸지 않는다. 목적 제조식 ID와 v.o2 인덱스가 일치하는 데이터만 사용한다.

## 작업물 보호
원본 게임 세이브·규칙·한글 번역·OXCE 실행파일은 수정하지 않는다. 재고와 확보 수량은 어디까지나 가상 모델의 계산값이다. 자동 검토 기록 이월 및 과거 메모 보존은 기존 시스템을 그대로 사용한다.

## 완료와 미완료
새 기능의 소스와 UI 및 CSV를 구현했다. Node 자동 테스트는 변경 모듈과 제조 계산기 관련 범위에서 실행한다. 브라우저 실제 사용자 조작, `main` 병합, 공개 웹사이트 배포, OXCE 실게임 제조 명령 직접 실행은 별도 미완료 상태다.
