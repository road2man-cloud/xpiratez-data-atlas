# X-Piratez v.o2 제조 계산기 — 누적 기록 제조식별 영향 탐색

기준: 2026-11-19. `8f5139a` 누적 검토 기록 기능에서 독립적으로 확장.

## 새 기능
- 여러 변경 차수의 *자동 제외된 검토 기록*을 과거 의존 제조식 ID로 집계한다.
- 제조식별 누적 제외 건수, 메모 존재 건수, 검토 표시 건수, 변경 차수 목록 및 가장 최근 차수를 표시한다.
- 관련 재료·조건 ID를 함께 보여준다. 제조식 ID나 관련 재료·조건 ID로 검색할 수 있다.
- 현재 작업표에 동일한 제조식 ID가 존재하면 그 작업으로 바로 이동한다. 이것은 작업 의미의 일치 판정이 아니라 **탐색 편의 기능**이다.
- 모든 제조식별 영향 요약을 CSV로 내보낸다.
- 제조식 영향 ID가 없는 제외 기록은 별도 계수하여 누락된 영향 범위를 드러낸다.

## 구현 파일
- `public/manufacture-v2/planner/route-history-impact.mjs` — 순수 분석·CSV 변환
- `public/manufacture-v2/planner/planner-ui.mjs` — 누적 기록 화면 탐색·이동·내보내기
- `public/manufacture-v2/planner/index.html`, `planner.css` — 제조식 영향 탐색 화면
- `tools/test-v2-route-action-board.mjs` — 집계 중복 방지, 소스 불변, CSV, 버전 오류 테스트

## 범위와 한계
- 이 기능은 X-Piratez **v.o2** 제조 계산기의 이전 검토 기록을 해석한다. 게임 세이브, 연구, 시설, 실제 제조 상태는 변경하지 않는다.
- 기록 간 제조식 ID가 같다는 것만으로 수량·연구·시설·선행조건까지 동일하다고 보지 않는다.
- 화면은 제조식 상위 100종까지 표시하며 CSV에는 집계 결과 전체를 포함한다.
- 현재 브라우저 탭 내 기록함을 사용한다. 지속 보관하려면 기존 기록함 JSON을 다운로드한다.
- 원본 게임 규칙·번역, 다른 브랜치, 원본 세이브는 수정하지 않았다.
