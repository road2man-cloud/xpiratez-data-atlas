# X-Piratez v.o2 제조 계산기 — 반복 변경 제조식 우선 검토

**작성:** 2026-11-19  
**기반 기능 커밋:** `4fe8a3e`  
**기능:** 누적 검토 기록과 **현재** 제조식·재료·조건을 안전하게 대조하는 작업 화면

- `public/manufacture-v2/planner/index.html`: 제조식 우선 검토 패널
- `public/manufacture-v2/planner/planner-ui.mjs`: 우선순위 필터, ID 검색, 선택 제조식 상세 대조, 현재 검토 작업표 이동, 두 종류 CSV 버튼

- `tools/test-v2-route-history-priority.mjs`: 변경 차수/과거 자료/현재 선행관계 분리, 외부 재료 가상 수량, 다른 v.o2 목표 거부 등 관련 테스트
- `package.json`: 제조 계산기 종합 검사 명령에 신규 모듈 테스트 연결

## 사용법

1. 제조 경로 작업대에서 재료 수량이나 제조 경로를 변경하고 `후속 부족 재료 계산 및 통합 작업표 갱신`을 실행한다.
2. 이전 검토 기록이 자동 제외되면 기존 `재계산 누적 기록함`에 보관된다.
3. 기록함 내 `반복 변경 제조식 우선 검토 · 이전/현재 재료·조건 비교`를 연다.
4. **최우선 / 다음 검토 / 현재 미검토 선행 작업 / 현재 계획에 없는 제조식**으로 제조식을 좁힌다.
5. 제조식을 선택하면 과거 영향 재료·조건 ID와 현재 제조 경로의 선행 작업·직접 입력·가상 조달 수량·상태 근거를 비교한다.
6. 필요한 현재 작업 ID를 클릭해 원래 통합 작업표의 검토·메모 입력으로 이동한다.
7. `제조식별 우선순위 CSV`에는 전체 제조식의 검토 순서와 차이 개요가, `재료·조건 전체 대조 CSV`에는 현재·과거에만 존재하는 항목을 포함한 전체 세부 내역이 보관된다.

## 우선순위 판정 (고정·설명 가능)

- **최우선:** 현재 제조식이 있고, 과거 변경 차수 2회 이상 + 현재 미검토 선행 작업이 존재하거나, 변경 차수 3회 이상
- **다음 검토:** 현재 제조식이 있고, 변경 차수 2회 이상 또는 현재 미검토 선행 작업이 존재
- **참고:** 현재 제조식이 있으나 위 조건 미충족
- **현재 계획 없음:** 과거 기록에서 영향받았지만 현재 같은 제조식 ID를 가진 노드가 없음

동일 등급 안에서는 변경 차수 수 → 미검토 관련 작업 수 → 과거 제외 기록 수 → 최근 차수 → 제조식 ID 순으로 정렬한다. 우선순위는 사용자의 **검토 순서 추천**이며 게임 제조 가능성을 증명하지 않는다.

## 보수적 동작

- 제조식 ID만 같은 현재 노드를 과거 노드와 완전히 같은 작업으로 간주하지 않는다.
- 현재의 관련 재료는 의존 작업표를 재귀적으로 추적하되 **직접 제조 입력**도 별도로 표시한다. 하위 제조에서 생산된 재료는 단순 외부 부족 재료로 중복 계산하지 않는다.
- 재료별로 사용자가 입력한 현재 재고, **가상 확보**, 계산 후 남은 부족을 별도 칸에 표시한다. 가격·실제 구매 가능성은 추정하지 않는다.
- 조건별로 현재 원장에 존재하는 근거 상태를 표시하고, 실제 시설·연구 해금 판정으로 대체하지 않는다.
- 과거 영향 목록에는 있었지만 현재 의존 경로에서 찾을 수 없는 재료·조건은 삭제하지 않고 **과거만 존재**로 별도 표시한다. 이전 수량·상태도 가능한 범위에서 함께 보여준다.
- 1.1 DB, 원본 규칙/한글 번역, 게임 세이브, OXCE EXE, 다른 작업자 브랜치는 변경하지 않는다.
- 현재 세션의 누적 메모는 브라우저 메모리 안에 있으므로 닫기 전에 기존 보관함 JSON을 다운로드해야 보존된다.
