# X-Piratez v.o2 병종 DB — 신병 초기 능력치 선발선 역산

**작성일:** 2026-11-21
**범위:** 기존 72개 출생처의 12종 비교표 상세 화면
**원본 규칙:** 2.1 v.o2 병종 색인, OXCE 생성 RNG, 현행 연구·시술 경로 기록

## 실제 구현

- `public/soldiers/modern/route-birth-screen-frontier.js`
  - 등록된 출생처 하나와 해당 출생처의 검증 가능한 **단일** 시술 후보 경로를 입력받는다.
  - 초기 실효 능력치 중 사용자가 선택한 **한 종의 가능한 모든 관측값**을 선발 최솟값 후보로 열거한다.
  - 현재 엔진의 `registeredRouteDistribution`을 재사용하여 각 선발선의 조건부 경로 분포, 최종 12종 합계 또는 선택 능력치의 기대값, 시술 능력치 요건 통과율을 산출한다.
  - 출생 시 해당 능력치 선발률 `P(S)`과 선발 집단에서의 시술 능력치 요건 충족률 `P(G|S)`을 별도 계산한다. 독립 신규 추첨 한 회에 둘을 충족할 확률 `p=P(S)P(G|S)`.
  - **독립적으로 같은 출생처를 N회 재추첨할 수 있다는 가정**의 하나 이상 충족 확률 `1-(1-p)^N`. 작은 확률에서의 부동소수 안정성을 위해 `-expm1(N*log1p(-p))`을 사용.
  - 선발만 통과할 때까지 필요한 평균 신규 추첨 횟수 `1/P(S)`, 두 조건 모두 통과할 때까지의 평균 횟수 `1/p`을 **가상 수학적 횟수**로 분리.
  - 사용자가 지정한 N과 최소 목표 확률을 통과하는 선발선 가운데 **조건부 최종 기대값**이 가장 높은 선발선을 선정하고, 기대값과 N회 내 성공 확률의 두 축에 한정한 비지배 선발선도 제공.
  - 통과 확률이 0이거나 원본 경로가 미해결인 조건은 기대값으로 승격하지 않고 별도 처리. 출생 RNG의 컷오프 수가 계산 한도를 초과하면 일부를 자의적으로 누락하지 않고 계산 보류한다.

- `public/soldiers/modern/route-birth-screen-view.js`
  - 기존 출생처 상세의 접이식 패널/표 UI. 출생 선발 대상 12종 중 하나, 최종 목표 12종·합계 중 하나, 신규 추첨 기회 N, 최소 성공 확률을 직접 조정.
  - 최종 평균, 출생 선발률, 시술 능력치 요건 통과율, 독립 추첨 1회당 결합 확률, N회 내 성공 확률, 기대 신규 추첨 횟수 및 두 축 비지배 여부를 동시에 표시.
  - 아주 작은 확률이나 큰 예상 추첨 횟수는 지수 표기로 표시해 의미 있는 수치가 0으로 사라지는 문제를 억제.

- `public/soldiers/modern/app.js`, `origin-catalog.css`, `index.html`
  - 기존 등록 경로 RNG 화면 안에 새 선발선 역산을 직접 추가. 별도 대시보드 생성 없음.
  - 선택한 결과의 **적용** 버튼은 기존 12종 입력을 명시적으로 초기화한 뒤, 해당 능력치 하나의 `atLeast` 기준으로 옮긴다. 기존 등록 후보·연구·시술/코르트 데이터는 재작성하지 않는다.
  - 이전부터 사용한 가상 전투 성장 위치·시행 횟수·성공률을 선택된 경로의 각 컷오프에도 동일하게 적용하며, 사용자에게 이 가정은 실제 OXCE XP 분포가 아님을 고지.

- `tools/check-route-birth-screen-frontier.mjs`
  - 재추첨 1회/여러 회 누적 확률, 1/p 역수, 출생 컷오프에 따른 선발률 변화, 능력치 요건 게이트와 성장 시점 차이, 최솟값 선택의 확률 제약, 실제 v.o2 대표 경로 1건 연동 검사.
- `tools/check-route-table-browser.mjs`
  - 신규 화면에서 목표·컷오프 계산·기존 채용 입력 반영 및 다른 병종 기능 보존 브라우저 흐름.

## 범위와 무효화 조건

- 이 계산은 **초기 출생 능력치 선발선 하나**와 선택한 등록 경로 한 개에 한정한다. 12종 능력치의 임의 조합 최적화 또는 병종·연구·훈련 경로의 전역 최적 탐색을 증명하지 않는다.
- 신규 대원 생성이 서로 독립이라는 확률 가정에 따른 순수 수학적 추첨 기회이다. 같은 출생처 병사를 게임 안에서 원하는 만큼 생성 가능하다는 증거는 아니다.
- 초기 영구 특성을 이미 포함한 실효 능력치를 사용한다. 전투·사격 실제 XP 획득 분포, 연구·재료·금액·시간·이벤트·시술 사용 가능성, 부상이나 훈장 기회는 확률에 포함하지 않는다.
- 능력치 게이트 통과율을 실제 게임에서 해당 변신을 수행할 확률로 부르면 안 된다. 컷오프별 조건부 평균을 선발 전에 모든 대원에게 기대할 수 있는 평균이라고 해석하면 안 된다.
- 원본 버전/해시, 경로 유효성, 코르트 독립 병종 분류, 72개 출생처 비교표를 보존한다.

## 수행한 검사

- `node tools/check-route-birth-screen-frontier.mjs` — 원본 v.o2 대표 경로 및 수학적 독립 추첨 확률 테스트 통과.
- `node tools/check-soldier-birth-selection.mjs` — 기존 실제 출생 능력치 선발/영구 보너스 회귀 통과.
- `node tools/check-route-table-browser.mjs` — 출생처 상세 패널에서 컷오프 전수 계산, 기존 입력 적용 및 기존 비교/후보 이동 검증 포함.

커밋 해시와 원격 배포 여부는 실제 Git 결과로만 판단한다.
