# X-Piratez v.o2 — 제조 검토 기록 변경 영향 추적 (2026-11-19)

## 새로 추가한 기능

같은 브라우저 제조 작업대에서 경로·재료 수량·가상 조달 계획을 수정해 재계산하는 경우, 이전 작업표를 즉시 버리지 않고 로컬 메모리에 잠시 보관한다.

1. 수정 전 통합 작업표와 검토 표시·메모를 읽어 v.o2 작업표 JSON 형식으로 보존한다.
2. 편집 경로 기준 일괄 계산을 수행한다. 남은 재료 부족이 없어도 `후속 부족 재료 계산 및 통합 작업표 갱신` 과정을 실행할 수 있다.
3. 새 통합 작업표의 모든 작업을 이전 작업표와 비교한다. 작업 종류, ID, 재료 수량, 상태, 세부 근거, 선행 의존 그래프를 함께 비교한다. 제조식 단계의 **표시 순서 번호만 바뀌는 경우**는 의미 변경으로 취급하지 않는다.
4. **동일한 의미를 갖는 단 하나의 작업**만 이전 검토 표시와 메모를 자동 이어받는다. 중복 후보는 임의로 대응하지 않으며, 변경·신규·모호 항목은 미검토로 남긴다.
5. 통합 작업표에서 `이번 변경·신규 중 재검토 대상` 필터로 영향받는 항목만 찾을 수 있다. 이미 사용자가 검토한 항목은 이 필터에서 빠진다.
6. 변경 영향 전체 CSV, 이전 검토·메모 JSON을 별도로 저장할 수 있다. 자동 제외된 이전 항목의 사유와 메모는 화면에서도 확인하며, 현재 동일 제조식 ID의 작업으로 이동할 수 있다.

## 주요 소스

- `public/manufacture-v2/planner/route-action-carryover.mjs` — 전체 현재 작업의 `unchanged / changed / new / ambiguous` 판정
- `public/manufacture-v2/planner/route-action-refresh.mjs` — 작업표 스냅샷, 안전한 검토 기록 복원, 변경 영향 CSV
- `public/manufacture-v2/planner/planner-ui.mjs` — 재계산 시 스냅샷 보존, 결과 복원, 변경 전후 화면 필터, 백업 버튼
- `public/manufacture-v2/planner/index.html`, `planner.css` — 실제 작업대 UI
- `tools/test-v2-route-action-board.mjs` — 재료 수량 변경 전파, 무관한 메모 보존, 제조식 위치 변경 및 신규 작업 분리 테스트

## 제한 사항과 보존 원칙

- 검토 표시와 메모는 **사용자 로컬 검토 기록**이다. 체크가 실제 재료 확보, 연구·시설 해금, 게임 제조 완료를 증명하지 않는다.
- 변경 전의 **제외된** 메모는 새 작업에 자동 복사하지 않는다. 별도 JSON으로 사용자가 내려받을 수 있지만, 브라우저 탭 종료 후 자동 영구 보존은 하지 않는다.
- 목적 제조식 ID가 다르면 이전 기록을 적용하지 않는다. 서로 다른 작업대/원본 게임 세이브/다른 작업자 브랜치 간 기록은 자동으로 혼합하지 않는다.
- 동일한 제조식 ID가 여러 번 등장하면, ID와 위치만으로 위험한 자동 대응을 하지 않는다.
- 구매 가능성·실제 가격·이벤트·연구/시설 잠금은 별도로 검증해야 한다.
- 이번 작업은 v.o2 전용 브라우저 소스 및 관련 테스트에 한정되며, 원본 세이브·규칙·번역 파일·OXCE 실행파일을 수정하지 않았다.
