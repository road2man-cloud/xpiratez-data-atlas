# X-Piratez 2.1 연구 상호배제와 병종별 최대 능력치 감사 (2026-11-01)

## 원본과 공개 사이트

- 원본: 설치된 XPiratez 2.1 / OXCE 8.7.1 Ruleset의 연구 4,629종, 변신 83종, SoldierBonus를 기반으로 최적화.
- 공개 병종 2.1 병합 DB: `public/data/soldiers-modern-index.json`의 연구 4,654종 (OXCE 기본 연구를 병합한 범위로 설치된 Piratez 고유 연구 수와 다름).
- **연구 direct `disables`**: 원본 기준 441건 = 양방향 134쌍(268개 간선) + 단방향 172건 + 자기 비활성화 1건. 사이트에서 병합 연구 전체로 다시 계산해 같은 441건임을 검증.
- 상호배제 직접 목록은 **사이트의 최신 2.1 연구 데이터에서 동적 생성**한다. 수동으로 ID를 나열한 제한된 목록이 아님.
- 영구 변화 비교 지표: 같은 병종을 유지하는 `soldierTransformation.soldierBonusType.stats`의 마나 제외 11종 변화량 합. 방어구/훈장/획득 시 자동 특성/전투 경험치/무작위 기본 스탯 변화는 **미포함**.
- 점수는 **연구·변신 정적 제약 조건의 최적화 해**로, 특정 게임 세이브에서 모든 연구·이벤트·무료 연구·재료·계급·훈장이 확보됐다는 증명은 아님.
- **2026-11-01 추가 감사 정정:** 원본 Captain's 11은 도둑 선장(`STR_CAPTAIN_THIEF`) 전용 이벤트와 보상이 있어야 얻을 수 있고, 빵과 물고기(`STR_BREAD_AND_FISHES_TRAINING`)는 사제 선장(`STR_CAPTAIN_PRIEST`) 전용이다. 이 두 선장 연구는 상호배제다. 기존 **영웅 +300** 및 **농부 +276** 조합은 이 상호배제를 위반하므로 무효이며, 명시적 제약을 추가해 **영웅 +282**, **농부 +261**로 재최적화했다. **이 숫자들도 시간순 연구·실전 획득이 인증된 값은 아니다.**
- 전체 29개 병종 중 **24개 병종에 정적 연구 순서 미해결 표시 53건**이 남아 있다. 정적 표시가 0건인 나머지 5개 역시 실제 플레이로 최종 달성되었다고 보증하지 않는다. **세이브에서 경로가 검증된 병종은 현재 0종**이다.

## 누락 방지 원칙

1. 연구를 완료하면 원본의 방향성 `disables`가 이전 완료 연구 상태를 무효화할 수 있다. 단방향을 근거 없이 양방향으로 바꾸지 않음.
2. `requires`(필수 가드)와 `dependencies`(일반 선행연구)를 구분하고 `unlocks` 우회를 반영. 비용 0 자동/이벤트 연구는 연구실에서 직접 완료됐다고 가정하지 않음.
3. `getOneFree`와 `getOneFreeProtected`는 연구 완료 때 후보 중 **1개 보상**이고, 보상 출처·가드·재시도·RNG를 기록. 이벤트 연구 지급도 발생이 증명된 경우만 실제 완료로 취급.
4. 변신 `requiredPreviousTransformations`·`forbiddenPreviousTransformations`는 원본 **방향성**을 따르며, 변신 이후 연구가 차단돼도 이미 획득한 변신 이력은 소급 취소되지 않음.
5. 모든 병사 변신 후보의 직접 필수 연구를 기존 완료 이력과 대조하여 **양방향 연구 `disables` 전수**를 사용한 상호배제 차단을 실행. Codex 3색 영웅 및 녹색 미인/붉은 기사/광신도 등 **확인된 간접 경로**는 별도 소스 기반 예외 검사.
6. `STR_PURE_MAIDEN_TRAINING`·`STR_REVOLUTIONARY_TRAINING`의 의식/파티/농민 혁명 선행 충돌 등 이벤트 우회가 완전히 반증되지 않은 간접 충돌은 **미확정 위험**으로 표시하고 확정 불가로 오판하지 않음.
7. 특정 사이트/게임 버전의 연구 파일이 서로 다른 경우 지표를 섞지 않음. 특히 기존 연구 DB v.o1.1.1로 최신 2.1 연구 해금을 증명하지 않음.

## 실행 검증

- `node tools/check-soldier-research-maxima.mjs`: 29종/11능력치/441건/134쌍/172건/1건, 원본 양방향 배제의 실제 변신 차단 검증. 선장 분기별 불가능 후보를 포함한 조합이 다시 상한으로 제시되면 검사 실패.
- `npm run check:soldiers:modern`, `npm run check:trainings`, `node tools/check-soldier-modern-browser.mjs`: 전체 기존 기능의 회귀검사와 실제 Chrome/Edge 화면 검증.
- UI: `/soldiers/modern/#researchMaxima` (29개 병종 조건부 최대치) 및 같은 페이지의 `#researchExclusionAudit` (직접 연구 배제 441건과 상세 원인).

## 최대치로 승격할 수 없는 한계와 반증 조건

각 병종의 연구·변신 후속 이벤트, 실물 아이템의 RNG/수량/월별 발생 제한, 동일 대원의 능력치 최저 조건, 전투/훈장·선장/여왕 진입, 실전 자원 소비를 모두 만족하는 **일련의 세이브 기반 실행 경로가 입증되기 전에는 '조건부 최대 후보'**로 유지한다.
원본 연구 규칙이 업데이트되어 `disables`·`requires`·`unlocks`·`getOneFree`가 바뀌거나, 과거 불가능했던 연구가 독립 이벤트로 지급되거나, 영구 보너스가 중복 적용되는 엔진 사실이 발견되면 다시 최적화해야 한다.
