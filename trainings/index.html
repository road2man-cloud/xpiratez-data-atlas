    실제 2.1 세이브로 현재 조건 확인

    OXCE 8.7.1 / v.o2 세이브를 브라우저에서만 읽습니다. 대원·기지 연구, 계급, 훈장, 자원과 변신 이력을 판정하며 파일을 업로드하지 않습니다.

    세이브 미적용 · 미래 조건만 검토합니다.

    검증 범위와 증거의 한계

    현재 규칙은 2.1 soldierTransformations와 OXCE 8.7.1 처리에 연결됩니다. 연구는 requires, dependencies, unlocks, getOneFree, 비용 0 자동 지급과 disables 순서를 구분합니다. 미래 연구가 실제 노출·완료·확률 당첨되었다고 가정하지 않습니다.

    현재 대원의 병종, 출생 보너스, 훈장과 이전 변신 이력을 사용합니다. 복제는 별도 병사이며, reset: true는 제거되는 이력을 지웁니다. 실제 전투 성장·체육관 성장 및 RNG가 미검증인 경우 가상 능력치 수치는 확정 최댓값으로 사용할 수 없습니다.
