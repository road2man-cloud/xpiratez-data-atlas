대원을 어떻게 키울까요?

출생처, 최종 병종, 선장 분기, 시술을 선택하고 실제 등록된 시간순 육성 경로를 비교하세요.

등록 후보는 연구·성장·자원 등의 조건부 재생 기록입니다. 게임 전체 최종 최고치는 아직 미증명이며, 훈장 자체 보너스를 제외한 영구 수치를 비교합니다.

어떤 대원을 찾고 있나요?

역할을 선택하면 관련 능력치를 우선순위대로 비교합니다. 전투 피해량이나 실제 승률 계산은 아닙니다.

비지배는 같은 최종 병종·난이도에서 선택한 역할 능력치가 모두 같거나 더 높고 하나라도 높은 다른 등록 경로가 없는 후보입니다. 난이도 미기록 경로는 비지배 판정에서 제외합니다. 코르트 등 특수 병종은 최종 병종 필터로 따로 비교하세요. 대표 표시는 경로를 삭제하지 않습니다. 역할 조건은 아래 육성 후보 목록에 적용되며, 분기 비교는 별도로 아래 정렬 기준을 사용합니다.

보유 특성 필터는 실제 특성 측정 자료가 연결된 경로에만 적용됩니다. 미기록은 특성이 없다는 뜻이 아닙니다.

계산 범위와 원장 출처

등록된 시간순 육성 기록 6종을 직접 불러옵니다. 연구·시술 교대 탐색은 각 그래프의 병종·보유 특성·계급·훈장별 능력치 대표만 비교 목록에 등록하며 전체 상태는 별도 원장에 보존합니다. 각 능력치는 동일 경로의 벡터이며 서로 다른 경로의 최고값을 합치지 않습니다. 합계 정렬은 파레토 최적성 증명이 아닙니다. 출생 범위, 자원·이벤트, 성장, 난수, 승급 등은 각 원장에 기록된 조건과 가정에 따릅니다.
