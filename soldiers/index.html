병종 DB

“병종”을 29개의 내부 바디 규칙으로 축약하지 않습니다. 실제 획득 루트마다 초기 고정 스탯·자동 특성이 다르면 별도 생성형으로 분리하고, 특성 능력치까지 합산한 실전 생성 스펙으로 비교합니다.

최종조합 출처
최종 기본형 (변형 후 포함)
실제 획득형 계산 기본 Soldier 랜덤치 → 획득 루트의 spawnedSoldier.currentStats 덮어쓰기 → 생성 시 transformationBonuses 능력치 합산 → OXCE 최소치 보정. 각 능력치는 현재 생성값 / 실효 성장캡으로 표시합니다. 실효 성장캡은 본체 statCaps에 생성 시 자동 특성의 능력치 보너스를 더한 값이며, 특수 생성 템플릿은 시작부터 성장캡을 넘을 수도 있습니다. 방어구 능력치는 포함하지 않습니다. 최종 강화 조합은 이미 받은 변환, 필수 이전 변환, 금지 이전 변환을 실제 순서대로 검사해 공존 가능한 강화만 묶습니다. requiredMinStats가 있으면 성장캡 안에서 필요한 최소 선성장까지 반영하고, OXCE의 Flat·현재값 비례·성장분 비례·랜덤 범위·스탯 상한 계산을 적용합니다.
